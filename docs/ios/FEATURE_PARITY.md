# مطابقة الوظائف: NOVA PDF Studio (Windows) ↔ NOVA Docs (iPhone/iPad)

**مفتاح الحالة:** COMPLETE = مكتوب ومختبر فعليًا · PARTIAL = يعمل جزئيًا أو مختبر في معاينة الويب فقط · BLOCKED = يتطلب شيئًا خارج هذه البيئة · NOT STARTED.

> تنبيه مهم: «مختبر» هنا يعني اختبارات آلية حقيقية على Linux (Vitest على الشيفرة نفسها + اختبار واجهة شامل في Chromium بمقاسات iPhone/iPad). **التشغيل على iOS نفسه (WKWebView + Swift) لم يُختبر بعد على جهاز أو محاكٍ** إلا ما يرد في نتيجة مسار CI على macOS (انظر TEST_RESULTS.md). لذلك وُسمت الوظائف المعتمدة على الشيفرة الأصلية Swift بـ PARTIAL حتى يثبت البناء والتشغيل.

## إعادة الاستخدام (لا إعادة بناء من الصفر)
| المكوّن الأصلي | في iOS | ملاحظة |
|---|---|---|

| `src/modules/*/shared` (pdfTools، applyEdits، editModel، calc، amountInWords، invoiceHtml، qr، formula، sheetModel، xlsx، extract) | مستعمل كما هو | |
| مستودعات `main/` (العملاء، المنتجات، الفواتير، الضرائب، الإعدادات، القوالب، الجداول، البيانات التجريبية) | مستعملة كما هي | عبر محرك SQLite للواجهة `src/platform/shims` |
| `pdfEngine.ts`، `rasterizeText.ts`، `searchablePdf.ts` | مستعملة كما هي | تعديل وحيد متوافق: معامل اختياري في `PdfEngine.load` |

| Electron/IPC/Node | **مفصول** | بدائل: Capacitor Filesystem/Preferences/Share + إضافات Swift |
