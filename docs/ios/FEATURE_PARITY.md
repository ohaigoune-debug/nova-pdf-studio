# مطابقة الوظائف: NOVA PDF Studio (Windows) ↔ NOVA Docs (iPhone/iPad)

**مفتاح الحالة:** COMPLETE = مكتوب ومختبر فعليًا · PARTIAL = يعمل جزئيًا أو مختبر في معاينة الويب فقط · BLOCKED = يتطلب شيئًا خارج هذه البيئة · NOT STARTED.

> تنبيه مهم: «مختبر» يعني اختبارات آلية حقيقية: Vitest على الشيفرة نفسها، اختبار واجهة شامل في Chromium بمقاسات iPhone/iPad، **وتشغيل على محاكي iOS الحقيقي** (iPhone 16 Pro Max وiPad Pro 13") مع 7 اختبارات StoreKit — انظر `TEST_RESULTS.md`. **لم يُختبر شيء على جهاز حقيقي بعد**، لذلك ما يعتمد على الكاميرا أو Pencil أو AirPrint أو المشاركة بقي PARTIAL.
