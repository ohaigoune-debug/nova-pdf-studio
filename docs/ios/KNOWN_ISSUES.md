# المشكلات المعروفة والقيود — NOVA Docs 1.0.0 (فرع feature/nova-docs-ios)

## تتطلب تدخلك أو بيئة Apple
1. **لا macOS/Xcode في بيئة العمل هذه (Linux).** كل شيفرة Swift كُتبت دون تجميع محلي؛ التجميع يتم فقط في مسار GitHub Actions على macOS. أي خطأ تجميع يظهر هناك (انظر TEST_RESULTS.md).
2. **حساب Apple Developer / الشهادات / الملفات التعريفية غير متاحة** ← لا IPA موقّع ولا TestFlight حتى تضيف أسرار App Store Connect API (انظر APP_STORE_CHECKLIST.md).
3. **Paid Apps Agreement + الحساب البنكي + الضرائب** ← بدونها لا تُحمَّل منتجات الشراء حتى في Sandbox (APPLE_PAYMENTS_SETUP.md).
4. **بريد ورابط الدعم + رابط سياسة الخصوصية** غير منشورة (الصفحات جاهزة في `site/nova-docs/`، والنشر ينتظر موافقتك).
5. توفر الاسم «NOVA Docs: PDF & Invoices» لا يُعرف إلا عند حجزه؛ يوجد ناشر آخر بتطبيقات «Nova Scanner/Nova Invoice».
6. Bundle ID `com.haigoune.novadocs` مقترح؛ إن كان محجوزًا غيّره عبر `NOVA_BUNDLE_ID`.

## قيود وظيفية (صريحة وموثقة في الواجهة)
- **تحرير النص الأصلي غير مدعوم**: «تعديل النص» = تبييض المقطع الأصلي + نص جديد بطبقة فوقه. النص القديم يبقى داخل الملف تحت الطبقة (يمكن استخراجه برمجيًا). للتنقيح الآمن لبيانات حساسة هذا **ليس** حذفًا حقيقيًا.
- النص غير اللاتيني (العربي…) المضاف بالتحرير يُدمج **كصورة عالية الدقة** (قيد pdf-lib في المحرك الأصلي) فلا يكون قابلًا للبحث؛ اللاتيني يُكتب نصًا حقيقيًا.
- العلامة المائية: نص لاتيني فقط.
- التحرير على صفحات مدوّرة (/Rotate ≠ 0) قد يضع الكائنات بإزاحة؛ يظهر تنبيه.
- الضغط لا يعيد ترميز الصور.
- طبقة النص الخفية (OCR): الأرقام داخل سطر عربي قد تُستخرج معكوسة في بعض القرّاء (مثال الاختبار: 12500 → 00521 عند الاستخراج بـ pdf.js). البحث بالكلمات العربية واللاتينية يعمل. (السلوك نفسه في نسخة Windows لأن الشيفرة مشتركة.)
- Tesseract حساس لحجم الخط: أُضيفت خوارزمية متعددة المقاييس (أصلحت حالة فعلية)، لكن الخطوط اليدوية والصور الرديئة جدًا تبقى أقل دقة.
- Apple Vision يُستعمل فقط إذا أعلن الجهاز دعمه لكل اللغات المطلوبة (العربية غير مضمونة حسب إصدار iOS) ← وإلا Tesseract تلقائيًا.
- تصدير الفاتورة PDF يعمل على iOS فقط (WebKit أصلي)؛ في معاينة الويب يظهر تنبيه.
- استيراد الفواتير القديمة: كشف تلقائي فقط (بلا رسم مناطق يدوي كما في Windows).
- الجداول: لا تنسيق خلايا/دمج/عرض أعمدة في iOS؛ «فاتورة من جدول» غير منفذة بعد.
- غير منفذ في iOS: مصمم القوالب، الملاحظات والمرفقات والحقول المخصصة، سجل التدقيق، قفل PIN.

## تقني
- حزمة الواجهة كبيرة (~1.7MB JS رئيسي + 7.7MB نواة Tesseract + 3.2MB لغات) — مقبول لتطبيق محلي لكنه يزيد حجم التطبيق.
- pdf.js «legacy» مستعمل لدعم iOS 16؛ أداء أبطأ قليلًا من النسخة الحديثة.
- نشر نتائج CI إلى فرع `ci/nova-docs-ios-results` يحتاج صلاحية كتابة لـ GITHUB_TOKEN في إعدادات Actions؛ إن رُفضت تبقى النتائج كـ Artifacts فقط.
- اختبار الواجهة الشامل يعمل على Chromium وليس WebKit؛ فروق WKWebView (Workers، WASM، CSP) يجب تأكيدها على المحاكي.
- شراء «معاينة الويب» (`platform/web/store.ts`) للتطوير فقط؛ لا يُستعمل على iOS أبدًا (Capacitor يختار إضافة Swift).
