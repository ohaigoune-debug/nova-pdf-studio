# تطبيق «مدرسة» الأصيل لأندرويد (1.1.0)

تطبيق أصيل بـ Kotlin و Jetpack Compose، مطابق لتطبيق الآيفون (`platform/ios`)، يحلّ محلّ غلاف الموقع (TWA) في `platform/android`.
لا صفحات ويب: يكلّم واجهة JSON نفسها التي يستعملها الآيفون (`/api/v1/ios/*`)، فلا يحتاج الخادم أي تحديث.

| | |
|---|---|
| الحزمة | `dz.madrasa.app` (نفس Play) — ونسخة التجربة `dz.madrasa.app.debug` تُثبَّت بجانبها |
| الإصدار | versionCode 8 · versionName 1.1.0 (في `gradle.properties`) |
| أندرويد | من 7.0 (API 24) — targetSdk 36 كما تشترط Google منذ 31 أوت 2026 |
| اللغة | العربية من اليمين إلى اليسار، بنصوص تطبيق الآيفون نفسها (`Strings.kt`) |

## ما فيه (مثل الآيفون)

- **الأبواب الأربعة**: الرئيسية، العب، منظّمي، حسابي — ولكل باب مكدّسه.
- **الرئيسية بالخانات الكبيرة**: دوراتي، البكالوريات السابقة، الفروض والاختبارات، الدروس المجانية، القسم العام، والتالي في المنظّم.
- **الدورات والدروس**: أقسام الدورة (الحصص، الفيديوهات، الفروض، الاختبارات، الملفات)، شروط الدورة، مواعيد الحصص.
- **الفيديو**: مشغّل Bunny الموقّع (أو يوتيوب) داخل إطار محمي، علامة مائية متحرّكة باسم التلميذ ورمزه،
  ونبضة كل 45 ثانية تفرض **جهازًا واحدًا** لكل حساب. لا حماية تسوّد الشاشة. أفقيًا يملأ الفيديو الشاشة والعلامة فوقه.
- **PDF**: عرض داخل التطبيق، وحفظ الملفات المسموح بها مختومة باسم التلميذ (من الخادم) للقراءة دون إنترنت.
- **بنك البكالوريات** بمرشّحات الشعبة والمادة والسنة، و**بنك الفروض**: الفصل ← السنة ← المادة، مع النسخ التفاعلية.
- **مدرسة PLAY**: المواد، الأقسام الأربعة (الدروس بالبطاقات، البكالوريات، الفروض، الاختبارات)، المواضيع تُحفظ وتُلعب دون إنترنت،
  الأنواع الثمانية من الأسئلة، تصحيح على الهاتف مطابق للخادم، XP والمستوى وأيام المواظبة، ومزامنة النتائج عند عودة الاتصال.
- **لعبة البطاقات**: بطاقة زرقاء تنقلب، أربعة أنواع (اختيار، فراغات، مطابقة، ترتيب)، جولة مختارة كالموقع.
- **منظّمي**: توقيت أسبوعي مقترح لكل شعبة حسب المعاملات وخارج أوقات الدراسة (الجمعة والسبت أطول)، حصص تُضاف وتُعدَّل،
  تذكير قبل الحصة بعشر دقائق بنص عام، وملخّص صباحي اختياري. الخطة على الهاتف فقط.
- **التسجيل اليدوي**: هاتف أو بريد + كلمة سر، إنشاء حساب كامل، ثم تأكيد الهاتف برمز (أو اتصال). لا Google ولا Apple.
- **حسابي**: طلباتي (تتبّع فقط، دون سعر)، الدعم والشكاوى، ملفاتي المحفوظة، المظهر، الخصوصية، الخروج، **حذف الحساب**.
- **القسم الافتراضي**: العام وقسم كل دورة، تعليق، إبلاغ عن تعليق، إخفاء تعليقات تلميذ على هذا الهاتف.
- **دون إنترنت**: آخر نسخة من كل صفحة تظهر مع تاريخ حفظها.

## ليس فيه (عن قصد)

- لا شراء، لا أسعار، لا كتالوج، لا روابط دفع: الدورات تُطلب من الموقع فقط.
- لا تسجيل بـ Google أو Apple.

## الفحص والبناء

- كل دفعة على الفرع `android-parity` تشغّل سير العمل `.github/workflows/android-native.yml`:
  اختبارات التصحيح (عيّنات الخادم نفسها التي يختبر بها الآيفون)، ثم بناء APK تجريبي و AAB غير موقّع،
  وجولة على كل الشاشات في محاكي أندرويد بلقطات شاشة (بخادم تجريبي موجود في نسخة debug فقط).
- لا مفتاح توقيع في GitHub أبدًا.

## الملف الموقّع للمتجر (على الخادم)

```sh
rm -rf /opt/madrasa/android-native-src \
  && git clone --depth 1 -b android-parity https://github.com/ohaigoune-debug/nova-pdf-studio /opt/madrasa/android-native-src \
  && bash /opt/madrasa/android-native-src/platform/android-native/scripts/build-aab-on-server.sh
```

يبني من نسخة مستقلة (لا يلمس `/opt/madrasa/platform` ولا تعديلاته المحلية)، ويقرأ المفتاح من `/opt/madrasa/android-key`
للقراءة فقط، ويضع `madrasa-1.1.0-native.aab` (وملف APK للتجربة) في `/opt/madrasa/android-release`.
ملاحظات الإصدار وتغييرات استمارات Play في `play-store/RELEASE-1.1.0-AR.md`.

## الخادم

يعمل على الخادم المنشور كما هو. مسارات الكتابة في `/api/v1/ios/*` تشترط الرأس `X-Madrasadz-Client: ios`،
فيرسله التطبيق مع `X-Madrasadz-Platform: android`. تحسين لاحق مقترح: أن يقبل الخادم `android` أيضًا،
وأن يرسل إشعارات المنصة إلى أندرويد عبر Firebase (اليوم يرسلها إلى الآيفون عبر Apple فقط).
