# دليل تأليف أسئلة MADRASADZ PLAY

كل ملف في `content/play/<grade>/<subject>/*.json` هو **مصفوفة JSON** من كائنات بالصيغة التالية (UTF-8، بلا تعليقات، بلا فواصل زائدة):

```json
{
  "key": "3AS-AR-U1-L2-0007",
  "type": "MCQ",
  "grade": "3AS",
  "streams": ["SCI", "MATH"],
  "subject": "AR",
  "unit": "U1",
  "lesson": "L2",
  "objective": "يميّز الطالب الاستعارة المكنية من التشبيه البليغ",
  "difficulty": "MEDIUM",
  "language": "ar",
  "question": "ما نوع الصورة البيانية في «ابتسم الصباح»؟",
  "options": ["تشبيه بليغ", "استعارة مكنية", "كناية", "مجاز مرسل"],
  "correct": 1,
  "explanation": "شُبّه الصباح بإنسان يبتسم، وحُذف المشبه به وأبقيت لازمة من لوازمه (الابتسام)؛ فهي استعارة مكنية.",
  "tags": ["بلاغة", "استعارة"]
}
```

## الحقول

| الحقل | الوصف |
|---|---|
| `key` | فريد وثابت: `GRADE-SUBJECT-UNIT-LESSON-NNNN` (4 أرقام). **يجب أن يطابق** `grade`/`subject`/`unit`/`lesson`. |
| `type` | `MCQ` أو `FILL_BLANK` (أو `MATCHING`/`ORDERING` لاحقاً) |
| `grade` | `4AM` / `1AS` / `2AS` / `3AS` |
| `streams` | الشعب المعنية (اختياري؛ غيابه = كل شعب السنة). رموز 1AS: `TC_SCI`, `TC_LIT`. رموز 2AS/3AS: `SCI`, `MATH`, `TM`, `GE`, `LIT`, `LANG` |
| `subject` | `AR MATH PHYS SVT FR EN HIST GEO ISL CIV PHILO ECO ACC LAW TECH INFO` |
| `unit` / `lesson` | رموز الوحدة والدرس كما في `catalog.json` (U1/L3 …) |
| `objective` | هدف تعليمي بجملة واحدة |
| `difficulty` | `EASY` / `MEDIUM` / `HARD` — بحسب المهارة المعرفية لا طول السؤال (سهل = تذكر/تعرف، متوسط = فهم/تطبيق، صعب = تحليل/تركيب/حالات ملتبسة) |
| `language` | `ar` افتراضياً؛ `fr` لأسئلة الفرنسية و`en` للإنجليزية (نص السؤال والخيارات بلغة المادة، والشرح يمكن أن يكون بالعربية أو بلغة المادة) |
| `question` | نص السؤال. في `FILL_BLANK` يُكتب الفراغ بـ `____` (4 شرطات سفلية على الأقل)، ويمكن أكثر من فراغ |
| `options` + `correct` | MCQ: **4 خيارات** متمايزة، إجابة صحيحة واحدة (`correct` فهرس 0–3). المشتتات منطقية وتختبر الفهم. |
| `blanks` + `bank` | FILL_BLANK: `blanks` إجابات الفراغات بالترتيب (كل عنصر نص أو مصفوفة بدائل مقبولة)، و`bank` بنك الكلمات الكامل (الإجابات + مشتتات) بين 4 و8 كلمات. كل إجابة يجب أن تكون موجودة حرفياً في `bank` (مع التشكيل نفسه). |
| `explanation` | 1–3 جمل: لماذا هذه الإجابة، ولماذا المشتت الرئيس خاطئ |
| `tags` | كلمات مفتاحية اختيارية |
| `verify` | اختياري للرياضيات/الفيزياء: `{"expression": "2*(3+4)", "expected": 14}` يُقيَّم آلياً (عمليات + - * / ^ sqrt abs ln log) |
| `reviewStatus` | اختياري: `NEEDS_REVIEW` إذا كان المؤلف غير متأكد من معلومة (تواريخ، أرقام رسمية، أسماء) |

## قواعد الجودة

1. محتوى **أصلي** يؤلَّف من المعرفة بالمنهاج الجزائري؛ لا نسخ من مواقع ولا بنوك خارجية ولا اقتباس نصوص أدبية طويلة محمية.
2. سؤال واحد = فكرة واحدة؛ لا تكرار الفكرة بصياغات سطحية مختلفة داخل الدرس.
3. الصحة أولاً: أي معلومة غير مؤكدة ⇒ `reviewStatus: "NEEDS_REVIEW"` أو حذف السؤال. لا تخمين يُقدَّم كحقيقة.
4. الإجابة الصحيحة لا تكون دائماً في الموضع نفسه (الخادم يخلط، لكن نوّع `correct` أيضاً).
5. الخيارات متقاربة الطول، لا «كل ما سبق»، لا «لا شيء مما سبق».
6. في اللغة العربية: ضبط بالشكل حيث يغيّر المعنى/الإعراب؛ في ملء الفراغ النحوي تكون المشتتات صوراً إعرابية للكلمة نفسها (نافعٌ/نافعًا/نافعٍ).
7. الرياضيات والفيزياء: أرقام بسيطة قابلة للتحقق؛ أضف `verify` كلما أمكن؛ اكتب الوحدات.
8. التاريخ/الجغرافيا/العلوم الإسلامية: التزم بما يدرَّس فعلاً في السنة؛ علّم التواريخ الدقيقة غير المؤكدة للمراجعة.
9. الفرنسية/الإنجليزية: أسئلة قواعد ومفردات وفهم قصيرة بلغة المادة؛ `language` مضبوط.
10. المستوى مناسب لعمر الطالب (4AM ≈ 15 سنة؛ 3AS ≈ 18 سنة).

## الحالات بعد الاستيراد

`AUTO_VALIDATED` (اجتاز الفحص البنيوي بلا تحذيرات) → يُقدَّم للطالب افتراضياً · `NEEDS_REVIEW` → لا يُقدَّم حتى يعتمده المشرف · `APPROVED`/`PUBLISHED` من لوحة الإدارة · `REJECTED` مستبعد.
