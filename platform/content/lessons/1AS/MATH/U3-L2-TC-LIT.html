الدالة التآلفية وتمثيلها بمستقيم

الهدف: أن تتعرّف على الدالة التآلفية f(x) = ax + b، وأن تمثّلها بمستقيم انطلاقًا من نقطتين، وأن تحدّد عبارتها من نقطتين معلومتين.

الفكرة في سطرين: الدالة التآلفية تتغير بوتيرة ثابتة: كلما زاد x بوحدة زاد f(x) بالمقدار a. لذلك تمثيلها البياني مستقيم، يقطع محور التراتيب عند b ويميل بحسب إشارة a وقيمته.

🔵 القواعد والمفاهيم

  1. الدالة التآلفية هي كل دالة من الشكل f(x) = ax + b حيث a و b عددان ثابتان. إذا كان b = 0 سُمّيت دالة خطية (تناسبية)، وإذا كان a = 0 كانت دالة ثابتة.
  2. التمثيل البياني لدالة تآلفية هو مستقيم. الدالة الخطية مستقيم يمرّ بالمبدأ، والدالة الثابتة مستقيم موازٍ لمحور الفواصل.
  3. معامل التوجيه a يقيس ميل المستقيم: إذا كان a > 0 فالدالة متزايدة (المستقيم يصعد)، وإذا كان a < 0 فهي متناقصة (المستقيم ينزل).
  4. الترتيب عند المبدأ b هو f(0)، أي ترتيب نقطة تقاطع المستقيم مع محور التراتيب.
  5. حساب a من نقطتين: إذا علمنا f(x1) و f(x2) مع x1 ≠ x2 فإن a = (f(x2) − f(x1)) ÷ (x2 − x1)، ثم نستنتج b بالتعويض في f(x) = ax + b.
  6. رسم المستقيم: يكفي حساب صورتي عددين مختلفين (يُفضَّل 0 وعدد بسيط آخر)، نعلّم النقطتين ثم نصل بينهما ونمدّ المستقيم.
  7. الزيادات متناسبة: إذا زاد x بالمقدار h زاد f(x) بالمقدار a × h.

🟢 أمثلة تطبيقية

  1. مثّل بيانيًا الدالة f(x) = 2x − 1. الحل: f(0) = −1 و f(2) = 3، فنعلّم النقطتين (0 ؛ −1) و(2 ؛ 3) ونصل بينهما. معامل التوجيه a = 2 موجب، فالمستقيم صاعد، والترتيب عند المبدأ b = −1.
  2. g دالة تآلفية تحقق g(1) = 3 و g(3) = 7. أوجد عبارتها. الحل: a = (7 − 3) ÷ (3 − 1) = 4 ÷ 2 = 2. ثم من g(1) = 3 نكتب 2 × 1 + b = 3، فـ b = 1. إذن g(x) = 2x + 1. التحقق: g(3) = 6 + 1 = 7 صحيح.
  3. حدّد اتجاه تغيّر الدالة h(x) = −3x + 5 واحسب نقطة تقاطع مستقيمها مع محور الفواصل. الحل: a = −3 < 0 فالدالة متناقصة. عند التقاطع مع محور الفواصل يكون h(x) = 0، أي −3x + 5 = 0، فـ x = 5/3. النقطة هي (5/3 ؛ 0).

🟠 أخطاء شائعة في البكالوريا

  • الخلط بين a وb: في f(x) = 3 − 2x يكون a = −2 و b = 3 وليس العكس.
  • حساب a بقسمة فرق الفواصل على فرق التراتيب (مقلوب القاعدة الصحيحة).
  • رسم المستقيم من نقطة واحدة فقط، أو عدم مدّه خارج النقطتين المحسوبتين.
  • اعتبار كل دالة تآلفية دالة تناسبية؛ التناسبية تتطلب b = 0 ومرور المستقيم بالمبدأ.

🟡 خلاصة للمراجعة السريعة

  • f(x) = ax + b: a معامل التوجيه، b الترتيب عند المبدأ = f(0).
  • التمثيل مستقيم؛ b = 0 ⇒ يمرّ بالمبدأ (دالة خطية).
  • a > 0 متزايدة، a < 0 متناقصة، a = 0 ثابتة.
  • a = (فرق الصور) ÷ (فرق الفواصل) ثم b بالتعويض.
  • للرسم: نقطتان مختلفتان تكفيان، والتحقق بنقطة ثالثة أفضل.
