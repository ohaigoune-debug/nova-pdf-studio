الحساب الحرفي: النشر والتحليل والمتطابقات الشهيرة

الهدف: أن تنشر عبارة جبرية وتبسّطها، وأن تحلّلها إلى جداء عوامل باستعمال العامل المشترك أو المتطابقات الشهيرة الثلاث، ثم توظّف التحليل في حل معادلة من الشكل «جداء يساوي صفرًا».

الفكرة في سطرين: النشر يحوّل جداء إلى مجموع، والتحليل يسير في الاتجاه المعاكس. المتطابقات الشهيرة تعمل في الاتجاهين: تجعل النشر أسرع والتحليل ممكنًا.

🔵 القواعد والمفاهيم

  1. النشر: تحويل جداء إلى مجموع بتوزيع الضرب على الجمع: k(a + b) = ka + kb، و(a + b)(c + d) = ac + ad + bc + bd. بعد النشر نُجمع الحدود المتشابهة ونرتّب حسب قوى x التنازلية.
  2. التحليل: تحويل مجموع إلى جداء عوامل؛ وهو العملية العكسية للنشر، ويفيد في حل المعادلات ودراسة الإشارة.
  3. المتطابقة الأولى: (a + b)² = a² + 2ab + b²؛ الثانية: (a − b)² = a² − 2ab + b²؛ الثالثة: (a − b)(a + b) = a² − b².
  4. التحليل بالعامل المشترك: إذا ظهر العامل نفسه في كل الحدود نُخرجه: ka + kb = k(a + b)، والعامل المشترك قد يكون عددًا أو x أو قوسًا كاملًا مثل (x + 2).
  5. التحليل بالمتطابقات: نتعرّف على a² − b² (فرق مربعين) أو على a² ± 2ab + b² (مربع كامل) بعد كتابة كل حد على شكل مربع.
  6. خاصية الجداء المعدوم: A × B = 0 يكافئ A = 0 أو B = 0. لذلك نحلّل العبارة قبل حل معادلة من الدرجة الثانية مثل (2x − 1)(x + 3) = 0.
  7. التحقق: لنتأكد من تحليل ننشر النتيجة؛ ولنتأكد من نشر نعوّض x بقيمة بسيطة في الطرفين.

🟢 أمثلة تطبيقية

  1. انشر وبسّط E = (2x + 3)² − (x − 5)(x + 5). الحل: (2x + 3)² = 4x² + 12x + 9، و(x − 5)(x + 5) = x² − 25. إذن E = 4x² + 12x + 9 − x² + 25 = 3x² + 12x + 34. التحقق عند x = 0: E = 9 − (−25) = 34 ✓.
  2. حلّل F = 9x² − 16 وG = x² − 6x + 9. الحل: F = (3x)² − 4² = (3x − 4)(3x + 4). وG = x² − 2 × 3 × x + 3² = (x − 3)².
  3. حلّل ثم حلّ المعادلة (x + 2)(3x − 1) − (x + 2)(x + 4) = 0. الحل: العامل المشترك (x + 2): العبارة = (x + 2)[(3x − 1) − (x + 4)] = (x + 2)(2x − 5). الجداء معدوم يعني x + 2 = 0 أو 2x − 5 = 0، أي x = −2 أو x = 5/2. مجموعة الحلول S = {−2 ; 5/2}.

🟠 أخطاء شائعة في البكالوريا

  • كتابة (a + b)² = a² + b² بنسيان الحد المضاعف 2ab؛ تحقّق بـ (1 + 1)² = 4 وليس 2.
  • خطأ الإشارة عند طرح قوس: −(x² − 25) = −x² + 25 وليس −x² − 25.
  • إخراج عامل مشترك ونسيان كتابة ما يبقى داخل القوس، مثل كتابة 3x + 3 = 3(x) بدل 3(x + 1).
  • قسمة طرفي معادلة جداء على (x + 2) فيضيع حل؛ استعمل خاصية الجداء المعدوم.

🟡 خلاصة للمراجعة السريعة

  • نشر: جداء ⟶ مجموع؛ تحليل: مجموع ⟶ جداء.
  • (a ± b)² = a² ± 2ab + b² و(a − b)(a + b) = a² − b².
  • للتحليل: ابحث أولًا عن عامل مشترك، ثم عن متطابقة شهيرة.
  • A × B = 0 ⇔ A = 0 أو B = 0.
  • تحقّق دائمًا بالنشر أو بتعويض قيمة بسيطة لـ x.
