الدوال المرجعية: x²، 1/x، |x|، الجذر التربيعي

الهدف: أن تعرف مجموعة تعريف واتجاه تغيّر وشكل منحنى كل من الدوال x ⟼ x² وx ⟼ 1/x وx ⟼ |x| وx ⟼ √x، وأن توظّفها لحل معادلات بسيطة ولمقارنة أعداد دون آلة حاسبة.

الفكرة في سطرين: أربع دوال «نموذجية»: المربّع والقيمة المطلقة زوجيتان ومنحنياهما متناظران بالنسبة إلى محور التراتيب، والمقلوب فردية ومنحناها متناظر بالنسبة إلى المبدأ، والجذر التربيعي معرّف على الأعداد الموجبة فقط ومتزايد.

🔵 القواعد والمفاهيم

  1. دالة المربّع x ⟼ x²: معرّفة على ℝ، زوجية لأن (−x)² = x²، متناقصة على ]−∞ ; 0] ومتزايدة على [0 ; +∞[، قيمتها الصغرى 0 عند 0. منحناها قطع مكافئ رأسه المبدأ.
  2. دالة المقلوب x ⟼ 1/x: معرّفة على ℝ*، فردية لأن 1/(−x) = −1/x، متناقصة على ]−∞ ; 0[ وعلى ]0 ; +∞[ (وليس على ℝ* كله). منحناها قطع زائد لا يقطع المحورين.
  3. دالة القيمة المطلقة x ⟼ |x|: معرّفة على ℝ وزوجية، تساوي −x على ]−∞ ; 0] وx على [0 ; +∞[، فهي متناقصة ثم متزايدة وقيمتها الصغرى 0. منحناها نصفا مستقيمين على شكل V.
  4. دالة الجذر التربيعي x ⟼ √x: معرّفة على [0 ; +∞[ فقط، متزايدة تمامًا، قيمتها الصغرى 0 عند 0. منحناها نصف قطع مكافئ.
  5. المقارنة بين x وx² و√x: على [0 ; 1]: x² ≤ x ≤ √x، وعلى [1 ; +∞[: √x ≤ x ≤ x²، وتتساوى عند 0 و1.
  6. المقارنة: لعددين موجبين a < b: a² < b² و√a < √b بينما 1/a > 1/b.

🟢 أمثلة تطبيقية

  1. حلّ في ℝ: x² = 5 ثم x² ≤ 4. الحل: x² = 5 ⇔ x = √5 أو x = −√5. x² ≤ 4 ⇔ −2 ≤ x ≤ 2 أي S = [−2 ; 2] (القطع المكافئ تحت المستقيم y = 4).
  2. قارن دون آلة: 1/3 و1/π، ثم (0,7)² و0,7 و√0,7. الحل: 0 < 3 < π ودالة المقلوب متناقصة على ]0 ; +∞[، إذن 1/3 > 1/π. وبما أن 0 < 0,7 < 1 فإن (0,7)² < 0,7 < √0,7 (0,49 < 0,7 < 0,83 تقريبًا).
  3. حلّ بيانيًا |x| ≥ 1. الحل: الشكل V فوق المستقيم y = 1 أو عليه عندما x ≤ −1 أو x ≥ 1، إذن S = ]−∞ ; −1] ∪ [1 ; +∞[.

🟠 أخطاء شائعة في البكالوريا

  • كتابة «دالة المقلوب متناقصة على ℝ*»؛ خطأ لأن −1 < 1 و1/(−1) < 1/1. الصواب: متناقصة على كل مجال على حدة.
  • حل x² = 5 بإعطاء x = √5 فقط ونسيان −√5.
  • الاعتقاد أن التربيع يكبّر العدد دائمًا؛ بين 0 و1 يكون x² أصغر من x.
  • حساب √(−4)؛ الجذر التربيعي معرّف على [0 ; +∞[ فقط.

🟡 خلاصة للمراجعة السريعة

  • x²: ℝ، زوجية، تنقص ثم تزيد، أصغر قيمة 0، قطع مكافئ.
  • 1/x: ℝ*، فردية، متناقصة على كل مجال على حدة، قطع زائد.
  • |x|: ℝ، زوجية، شكل V، أصغر قيمة 0 عند 0.
  • √x: [0 ; +∞[، متزايدة، نصف قطع مكافئ.
  • على [0 ; 1]: x² ≤ x ≤ √x، وبعد 1 ينقلب الترتيب.
