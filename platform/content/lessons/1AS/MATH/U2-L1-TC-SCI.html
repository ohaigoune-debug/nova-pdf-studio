مفهوم الدالة ومجموعة التعريف والتمثيل البياني

الهدف: أن تتعرّف على الدالة العددية كعلاقة تربط كل عدد بصورة وحيدة، وأن تحدّد مجموعة تعريفها من عبارتها، وأن تحسب صورًا وسوابق جبريًا وبيانيًا.

الفكرة في سطرين: الدالة f «آلة» تأخذ عددًا x وتعيد عددًا واحدًا f(x) يسمّى صورته، ومجموعة التعريف هي الأعداد التي تقبلها الآلة. التمثيل البياني هو مجموعة النقط M(x ; f(x))؛ نقرأ عليه عموديًا للصورة وأفقيًا للسوابق.

🔵 القواعد والمفاهيم

  1. الدالة العددية: علاقة f تُرفق بكل عدد x من مجموعة D عددًا حقيقيًا وحيدًا يُرمز له f(x). نكتب f : x ⟼ f(x).
  2. الصورة والسابقة: f(x) صورة x، وx سابقة للعدد f(x). لكل عدد صورة وحيدة، لكن قد يكون لعدد عدة سوابق أو لا سابقة له.
  3. مجموعة التعريف Df: مجموعة الأعداد x التي يمكن حساب f(x) من أجلها؛ تُعطى في النص أو تُستنتج من العبارة.
  4. قاعدتا تحديد Df: المقام غير معدوم (نحذف قيم x التي تُعدمه)، وما تحت الجذر التربيعي موجب أو معدوم (نحلّ متراجحة).
  5. التمثيل البياني: المنحنى Cf هو مجموعة النقط M(x ; y) حيث x ∈ Df وy = f(x). النقطة A(a ; b) ∈ Cf إذا وفقط إذا كان f(a) = b.
  6. القراءة البيانية: لصورة a نرسم المستقيم العمودي x = a ونقرأ ترتيب تقاطعه مع المنحنى. لسوابق b نرسم المستقيم الأفقي y = b ونقرأ فواصل نقط التقاطع.
  7. جدول القيم: لرسم المنحنى نحسب f(x) لقيم مختارة ثم نعلّم النقط ونصل بينها بخط انسيابي.

🟢 أمثلة تطبيقية

  1. لتكن f(x) = 2x − 3. احسب f(0) وf(2) وf(−1) ثم أوجد سابقة العدد 7. الحل: f(0) = −3، f(2) = 1، f(−1) = −5. السابقة: 2x − 3 = 7 ⇒ x = 5. تحقق: f(5) = 7.
  2. حدّد مجموعة تعريف g(x) = (x + 1)/(x² − 4) وh(x) = √(x + 3). الحل: g معرّفة إذا كان x² − 4 ≠ 0 أي x ≠ ±2، فـ Dg = ℝ \ {−2 ; 2}. وh معرّفة إذا كان x + 3 ≥ 0، فـ Dh = [−3 ; +∞[.
  3. لتكن f(x) = x² − 1. هل تنتمي النقطة A(3 ; 8) إلى Cf؟ وما سوابق العدد 3؟ الحل: f(3) = 8 = ترتيب A، إذن A ∈ Cf. السوابق: x² − 1 = 3 ⇒ x² = 4 ⇒ x = ±2. أمّا −5 فلا سابقة له لأن x² = −4 مستحيل.

🟠 أخطاء شائعة في البكالوريا

  • الخلط بين الصورة والسابقة: «احسب صورة 2» يعني f(2)، أمّا «أوجد سوابق 2» فيعني حل المعادلة f(x) = 2.
  • اعتبار أن لكل عدد سابقة وحيدة؛ الوحدانية تخص الصورة فقط.
  • حل x + 3 > 0 بدل x + 3 ≥ 0 عند الجذر؛ الصفر مقبول تحت الجذر.
  • الحكم على انتماء نقطة إلى المنحنى بالنظر فقط؛ يجب التحقق بالحساب f(a) = b.

🟡 خلاصة للمراجعة السريعة

  • دالة = لكل x من Df صورة وحيدة f(x).
  • مقام ≠ 0 ؛ تحت الجذر ≥ 0 ⇒ هكذا نجد Df.
  • صورة a: احسب f(a). سوابق b: حلّ f(x) = b.
  • A(a ; b) ∈ Cf ⇔ f(a) = b.
  • بيانيًا: عمودي للصورة، أفقي للسوابق.
