الترتيب في ℝ والمجالات

الهدف: أن تقارن عددين حقيقيين بطرق مختلفة، وأن تستعمل خواص الترتيب مع العمليات الأربع، وأن تكتب مجموعة أعداد على شكل مجال وتحدّد تقاطع مجالين واتحادهما.

الفكرة في سطرين: المستقيم المدرّج يرتّب الأعداد الحقيقية، والمجال «قطعة» منه. الجمع يحافظ على الترتيب دائمًا، أمّا الضرب فيحافظ عليه إذا كان المضروب فيه موجبًا ويعكسه إذا كان سالبًا.

🔵 القواعد والمفاهيم

  1. المقارنة بالفرق: a ≤ b يكافئ a − b ≤ 0. فلمقارنة عددين ندرس إشارة فرقهما، وهذه أعمّ طريقة.
  2. الجمع والطرح: إذا كان a ≤ b فإن a + c ≤ b + c لكل عدد حقيقي c. وإذا كان a ≤ b وc ≤ d فإن a + c ≤ b + d (نجمع متباينتين في الاتجاه نفسه، ولا نطرحهما).
  3. الضرب: إذا كان a ≤ b وc > 0 فإن ac ≤ bc. وإذا كان c < 0 فإن ac ≥ bc: الضرب في عدد سالب يعكس اتجاه المتباينة.
  4. المقلوب والمربع: إذا كان 0 < a ≤ b فإن 1/a ≥ 1/b وa² ≤ b² و√a ≤ √b. أمّا إذا كان a ≤ b ≤ 0 فإن a² ≥ b².
  5. المجالات المحدودة: [a ; b] مغلق يحوي طرفيه، ]a ; b[ مفتوح لا يحويهما، و[a ; b[ و]a ; b] نصف مفتوحين. طول المجال هو b − a.
  6. المجالات غير المحدودة: [a ; +∞[ هي مجموعة x بحيث x ≥ a، و]−∞ ; a[ هي x < a. القوس عند ∞ مفتوح دائمًا، وℝ = ]−∞ ; +∞[.
  7. التقاطع والاتحاد: I ∩ J مجموعة الأعداد التي تنتمي إلى I وJ معًا، وI ∪ J مجموعة الأعداد التي تنتمي إلى I أوJ. يُحدَّدان بسهولة بالرسم على المستقيم المدرّج.

🟢 أمثلة تطبيقية

  1. قارن 3/7 و2/5. الحل: 3/7 − 2/5 = 15/35 − 14/35 = 1/35 > 0، إذن 3/7 > 2/5.
  2. إذا كان 2 ≤ x ≤ 5 فاحصر العددين 3x + 1 و−2x. الحل: بالضرب في 3 ثم إضافة 1: 7 ≤ 3x + 1 ≤ 16. وبالضرب في −2 ينعكس الاتجاه: −10 ≤ −2x ≤ −4.
  3. ليكن I = [−1 ; 4] وJ = ]2 ; +∞[. حدّد I ∩ J وI ∪ J. الحل: الأعداد المشتركة هي التي تحقق 2 < x ≤ 4، أي I ∩ J = ]2 ; 4]. والاتحاد يبدأ من −1 (مع الطرف) ولا ينتهي: I ∪ J = [−1 ; +∞[.

🟠 أخطاء شائعة في البكالوريا

  • نسيان عكس اتجاه المتباينة عند الضرب أو القسمة على عدد سالب: من x ≤ 3 نستنتج −x ≥ −3 وليس −x ≤ −3.
  • طرح متباينتين طرفًا لطرف؛ الطرح غير مسموح، بل نضرب الثانية في −1 ثم نجمع.
  • كتابة قوس مغلق عند ∞ مثل [2 ; +∞]؛ اللانهاية ليست عددًا فالقوس عندها مفتوح دائمًا.
  • الخلط بين التقاطع «و» (الأصغر) والاتحاد «أو» (الأكبر)؛ الرسم على المستقيم يحسم الأمر.

🟡 خلاصة للمراجعة السريعة

  • a ≤ b ⇔ a − b ≤ 0.
  • الجمع يحافظ على الترتيب؛ الضرب في موجب يحافظ، وفي سالب يعكس.
  • لعددين موجبين: الترتيب نفسه للمربعات والجذور، ومعكوس للمقلوبات.
  • [ مغلق = الطرف ينتمي، ] مفتوح = لا ينتمي، وعند ∞ مفتوح دائمًا.
  • ∩ = الجزء المشترك، ∪ = كل ما يغطّيه أحدهما؛ ارسم المستقيم المدرّج.
