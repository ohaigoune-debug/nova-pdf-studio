القيمة المطلقة

الهدف: أن تعرّف القيمة المطلقة وتفسّرها كمسافة على المستقيم المدرّج، وأن تحلّ معادلات ومتراجحات من الشكل |x − a| = r و|x − a| ≤ r، وأن تكتب مجالًا بالقيمة المطلقة.

الفكرة في سطرين: القيمة المطلقة لعدد هي بُعده عن الصفر، فهي دائمًا موجبة أو معدومة. و|x − a| تقيس المسافة بين x وa، لذلك |x − a| ≤ r تعني أن x في المجال المتمركز حول a ونصف قطره r.

🔵 القواعد والمفاهيم

  1. التعريف: |x| = x إذا كان x ≥ 0، و|x| = −x إذا كان x < 0. مثلًا |7| = 7 و|−7| = 7 و|0| = 0.
  2. التفسير الهندسي: |x| مسافة النقطة ذات الفاصلة x عن المبدأ، و|a − b| = |b − a| المسافة بين النقطتين a وb.
  3. خواص: |x| ≥ 0، و|x| = 0 يكافئ x = 0، و|−x| = |x|، و√(x²) = |x|، و|a × b| = |a| × |b|.
  4. المعادلة |x| = r: حلّان r و−r إذا كان r > 0، الحل 0 إذا كان r = 0، ولا حل إذا كان r < 0.
  5. المعادلة |x − a| = r (مع r ≥ 0): تكافئ x = a + r أو x = a − r: النقطتان اللتان بُعدهما عن a يساوي r.
  6. المتراجحة |x − a| ≤ r (مع r > 0): تكافئ a − r ≤ x ≤ a + r، فالحلول هي المجال [a − r ; a + r] مركزه a ونصف قطره r. أمّا |x − a| ≥ r فتعطي x ≤ a − r أو x ≥ a + r.
  7. من المجال إلى القيمة المطلقة: [m ; n] يُكتب |x − a| ≤ r حيث a = (m + n)/2 وr = (n − m)/2.

🟢 أمثلة تطبيقية

  1. اكتب |2 − √5| دون رمز القيمة المطلقة. الحل: بما أن √5 > √4 = 2 فإن 2 − √5 < 0، ومنه |2 − √5| = −(2 − √5) = √5 − 2.
  2. حلّ في ℝ المعادلة |x − 3| = 5. الحل: الأعداد التي بُعدها عن 3 يساوي 5: x = 3 + 5 = 8 أو x = 3 − 5 = −2، إذن S = {−2 ; 8}. التحقق: |−2 − 3| = |−5| = 5.
  3. حلّ |x + 1| ≤ 3 ثم اكتب ]1 ; 7[ بقيمة مطلقة. الحل: |x + 1| ≤ 3 تكافئ −3 ≤ x + 1 ≤ 3 أي −4 ≤ x ≤ 2، فـ S = [−4 ; 2]. وللمجال ]1 ; 7[: المركز (1 + 7)/2 = 4 ونصف القطر (7 − 1)/2 = 3، فيُكتب |x − 4| < 3.

🟠 أخطاء شائعة في البكالوريا

  • الاعتقاد أن −x سالب دائمًا؛ إذا كان x = −3 فإن −x = 3 موجب و|x| = −x.
  • إعطاء حل واحد للمعادلة |x − 3| = 5 ونسيان x = −2.
  • كتابة حل |x − a| ≥ r مجالًا واحدًا؛ الصحيح اتحاد مجالين ]−∞ ; a − r] ∪ [a + r ; +∞[.
  • الخلط بين المركز ونصف القطر في |x − 4| < 3: المركز 4 ونصف القطر 3.

🟡 خلاصة للمراجعة السريعة

  • |x| = x إذا كان x ≥ 0، و−x إذا كان x < 0؛ دائمًا ≥ 0.
  • |a − b| = المسافة بين a وb.
  • |x − a| = r ⇔ x = a + r أو x = a − r.
  • |x − a| ≤ r ⇔ x ∈ [a − r ; a + r] (مجال مركزه a ونصف قطره r).
  • [m ; n] ⇔ |x − (m + n)/2| ≤ (n − m)/2.
