التوازي في الفضاء

الهدف: أن تعرف خواص التوازي في الفضاء وأن توظّفها في البرهان وفي إنشاء مقاطع مستوية لمجسّم، خاصة بنظرية السقف.

الفكرة في سطرين: التوازي ينتقل في الفضاء: من مستقيم إلى مستقيم عبر ثالث، ومن مستقيم إلى مستوٍ عبر مستقيم محتوى فيه، ومن مستوٍ إلى مستوٍ عبر مستقيمين متقاطعين. ونظرية السقف تعطي اتجاه تقاطع مستويين دون حساب.

🔵 القواعد والمفاهيم

  1. تعدّي توازي المستقيمات: مستقيمان موازيان لمستقيم ثالث متوازيان.
  2. مستقيم يوازي مستوياً: إذا كان d يوازي مستقيماً d' محتوى في المستوي P، وكان d غير محتوى في P، فإن d // P.
  3. خاصية عكسية مهمة: إذا كان d // P، فكل مستوٍ Q يحوي d ويقطع P يقطعه وفق مستقيم يوازي d.
  4. توازي مستويين: إذا احتوى المستوي P مستقيمين متقاطعين يوازيان المستوي Q، فإن P // Q. ولا يكفي مستقيم واحد.
  5. تعدّي توازي المستويات: مستويان موازيان لمستوٍ ثالث متوازيان.
  6. مستويان متوازيان ومستوٍ قاطع: إذا كان P // Q وقطع مستوٍ R المستوي P وفق d، فإنه يقطع Q وفق d' مع d // d'.
  7. نظرية السقف: إذا كان d // d' مع d محتوى في P وd' محتوى في Q، والمستويان P وQ متقاطعان وفق Δ، فإن Δ // d // d'.

🟢 أمثلة تطبيقية

  1. في المكعّب ABCDEFGH، برهن أن (EG) // (ABC). الحل: الرباعي ACGE مستطيل، فـ (EG) // (AC). المستقيم (AC) محتوى في (ABC) و(EG) غير محتوى فيه، إذن (EG) // (ABC).
  2. برهن أن (ABF) // (DCG). الحل: (AB) // (DC) و(DC) محتوى في (DCG)، فـ (AB) // (DCG). وكذلك (AE) // (DH) فـ (AE) // (DCG). المستقيمان (AB) و(AE) متقاطعان في A ومحتويان في (ABF)، إذن (ABF) // (DCG).
  3. لتكن M نقطة من [EH] مختلفة عن طرفيها. عيّن تقاطع المستوي (ABM) مع المستوي (EFG). الحل: النقطة M مشتركة بين المستويين. (AB) محتوى في (ABM) و(EF) محتوى في (EFG) و(AB) // (EF)، فحسب نظرية السقف يكون التقاطع هو المستقيم المار بـ M والموازي لـ (AB)؛ وهو يقطع [FG] في نقطة N، فيكون المقطع الرباعي ABNM.

🟠 أخطاء شائعة في البكالوريا

  • الاستنتاج أن مستويين متوازيان لأن مستقيماً واحداً من الأول يوازي الثاني؛ الشرط يتطلب مستقيمين متقاطعين.
  • كتابة «d // P إذن d يوازي كل مستقيم في P»: الصحيح أنه يوازي مستقيماً واحداً على الأقل فيه.
  • تطبيق نظرية السقف دون التأكد من أن المستقيمين متوازيان فعلاً وأن كلاً منهما محتوى في مستواه.
  • نسيان الشرط «d غير محتوى في P» عند البرهان على توازي مستقيم ومستوٍ.

🟡 خلاصة للمراجعة السريعة

  • d // d' وd' محتوى في P وd خارج P ⇒ d // P.
  • مستقيمان متقاطعان من P يوازيان Q ⇒ P // Q.
  • نظرية السقف: d // d' في مستويين متقاطعين ⇒ التقاطع يوازيهما.
  • لإنشاء مقطع: ابحث عن نقطة مشتركة ثم عن اتجاه التقاطع.
