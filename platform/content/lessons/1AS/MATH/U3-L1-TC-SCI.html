المعادلات من الدرجة الأولى بمجهول واحد

الهدف: أن تحلّ في ℝ معادلة من الدرجة الأولى بمجهول واحد، بما فيها المعادلات التي تحوي أقواسًا أو مقامات عددية أو معادلات جداء معدوم، وأن تناقش حالات المعادلة ax + b = 0 حسب قيم a وb.

الفكرة في سطرين: المعادلة مساواة فيها مجهول، وحلّها يعني إيجاد كل القيم التي تجعلها صحيحة. نحوّل المعادلة إلى معادلات مكافئة أبسط بإضافة نفس العدد إلى الطرفين أو ضربهما في نفس العدد غير المعدوم، حتى نعزل المجهول في طرف واحد.

🔵 القواعد والمفاهيم

  1. المعادلة من الدرجة الأولى بمجهول واحد هي كل معادلة يمكن كتابتها على الشكل ax + b = 0 حيث a وb عددان حقيقيان، وحلّها هو كل عدد يجعل المساواة صحيحة.
  2. المعادلتان المتكافئتان لهما نفس مجموعة الحلول. نحصل على معادلة مكافئة إذا أضفنا نفس العدد إلى الطرفين، أو ضربنا الطرفين في نفس العدد غير المعدوم.
  3. مناقشة ax + b = 0: إذا كان a ≠ 0 فالحل الوحيد x = −b/a. إذا كان a = 0 وb ≠ 0 فلا حل (S = ∅). إذا كان a = 0 وb = 0 فكل عدد حقيقي حل (S = ℝ).
  4. معادلة الجداء المعدوم: A × B = 0 يكافئ A = 0 أو B = 0. وهي الطريقة الوحيدة لحل معادلات مثل (x − 2)(3x + 1) = 0 دون نشر.
  5. المعادلات ذات المقامات العددية: نضرب الطرفين في المضاعف المشترك الأصغر للمقامات لنتخلص من الكسور.
  6. التحقق: نعوّض القيمة المحصّلة في المعادلة الأصلية؛ إن تساوى الطرفان فالحل صحيح.
  7. المسائل: نختار المجهول، نترجم نص المسألة إلى معادلة، نحلّها، ثم نتأكد أن الحل مقبول في سياق المسألة.

🟢 أمثلة تطبيقية

  1. حلّ في ℝ: 5x − 7 = 2x + 8. الحل: 5x − 2x = 8 + 7، أي 3x = 15، ومنه x = 5. التحقق: 5(5) − 7 = 18 و 2(5) + 8 = 18. إذن S = {5}.
  2. حلّ في ℝ: x/2 + x/3 = 10. الحل: نضرب الطرفين في 6: 3x + 2x = 60، أي 5x = 60، ومنه x = 12. التحقق: 6 + 4 = 10. إذن S = {12}.
  3. حلّ في ℝ: (2x − 6)(x + 4) = 0. الحل: جداء معدوم، إذن 2x − 6 = 0 أو x + 4 = 0، أي x = 3 أو x = −4. إذن S = {−4 ; 3}.

🟠 أخطاء شائعة في البكالوريا

  • نقل حدّ من طرف إلى آخر دون تغيير إشارته، مثل كتابة 5x + 2x = 8 − 7 في المثال الأول.
  • القسمة على عبارة تحوي المجهول: من x² = 3x يستنتج التلميذ x = 3 فقط ويضيّع الحل x = 0؛ الصواب x(x − 3) = 0.
  • نشر الجداء المعدوم (x − 2)(x + 5) = 0 بدل تطبيق القاعدة مباشرة، فتظهر معادلة من الدرجة الثانية لا يعرف حلّها.
  • كتابة «x = 5» دون مجموعة الحلول S = {5}، أو نسيان حالة a = 0 عند مناقشة معادلة بوسيط.

🟡 خلاصة للمراجعة السريعة

  • ax + b = 0 مع a ≠ 0 ⇒ x = −b/a.
  • a = 0 وb ≠ 0 ⇒ S = ∅ ؛ a = 0 وb = 0 ⇒ S = ℝ.
  • نقل حدّ = تغيير إشارته؛ الضرب أو القسمة على عدد غير معدوم فقط.
  • A × B = 0 ⇔ A = 0 أو B = 0.
  • التحقق بالتعويض ثم كتابة S في النهاية.
