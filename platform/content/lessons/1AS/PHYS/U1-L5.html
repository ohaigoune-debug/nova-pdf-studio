التقدم وجدول التقدم والمتفاعل المحد

الهدف: أن تنشئ جدول تقدم تفاعل كيميائي، وأن تحدّد التقدم الأعظمي والمتفاعل المحدّ وتركيب الجملة في الحالة النهائية.

الفكرة في سطرين: التقدم x (بالمول) يقيس «كم مرة» حدث التفاعل كما تصفه المعادلة: كل متفاعل ينقص بمقدار معامله × x وكل ناتج يزيد بمعامله × x. يتوقف التفاعل عندما ينفد أحد المتفاعلات، وهو المتفاعل المحدّ، فيكون التقدم عندها أعظمياً xmax.

🔵 القواعد والمفاهيم

  1. التقدم x مقدار بالمول يبدأ من 0 ويزداد أثناء التفاعل؛ لمعادلة a A + b B → c C + d D نكتب: n(A) = n0(A) − a·x، وn(C) = c·x.
  2. جدول التقدم يضم ثلاثة أسطر: الحالة الابتدائية (x = 0)، الحالة الوسيطة (x)، والحالة النهائية (xmax).
  3. التقدم الأعظمي xmax هو أصغر قيمة لـx تجعل كمية مادة أحد المتفاعلات معدومة.
  4. المتفاعل المحدّ هو الذي ينعدم أولاً ويوقف التفاعل؛ المتفاعل الآخر بزيادة.
  5. المزيج الستوكيومتري: إذا تحقق n0(A) / a = n0(B) / b فإن المتفاعلين ينفدان معاً.
  6. كميات المادة في الحالة النهائية تُحسب بتعويض xmax في سطر الحالة الوسيطة.

🟢 أمثلة تطبيقية

  1. نمزج 3 mol من H2 و2 mol من O2 وفق 2H2 + O2 → 2H2O. الحل: 3 − 2x = 0 يعطي x = 1.5؛ و2 − x = 0 يعطي x = 2؛ إذن xmax = 1.5 mol وH2 هو المحدّ. الحالة النهائية: n(H2) = 0، n(O2) = 0.5 mol، n(H2O) = 3 mol.
  2. Fe + 2H+ → Fe2+ + H2 مع n0(Fe) = 0.1 mol وn0(H+) = 0.3 mol. الحل: 0.1 − x = 0 يعطي 0.1؛ 0.3 − 2x = 0 يعطي 0.15؛ إذن xmax = 0.1 mol والحديد محدّ. يبقى n(H+) = 0.3 − 0.2 = 0.1 mol، ويتشكل n(H2) = 0.1 mol، أي حجم V = 0.1 × 24 = 2.4 L في الشروط العادية.

🟠 أخطاء شائعة في البكالوريا

  • اختيار xmax الأكبر بدل الأصغر؛ الأصغر هو الذي يوقف التفاعل أولاً.
  • نسيان ضرب x في المعامل الستوكيومتري (كتابة 3 − x بدل 3 − 2x).
  • الحكم على المتفاعل المحدّ بمقارنة كميات المادة الابتدائية مباشرة دون القسمة على المعاملات.
  • كتابة كمية مادة الناتج في الحالة الابتدائية بغير الصفر عندما لا يكون موجوداً أصلاً.

🟡 خلاصة للمراجعة السريعة

  • متفاعل: n0 − (معامل)·x؛ ناتج: (معامل)·x.
  • xmax = أصغر قيمة تُعدم أحد المتفاعلات.
  • المتفاعل المحدّ ينفد؛ الآخر يبقى بزيادة.
  • مزيج ستوكيومتري: n0(A)/a = n0(B)/b.
  • الحالة النهائية = تعويض xmax في السطر الوسيط.
