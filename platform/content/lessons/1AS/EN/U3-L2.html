Expressing cause and result (because, so, therefore)

Goal: To link a cause and its result with because, so, therefore, as, since, as a result and that is why, using the correct position and punctuation of each connector.

The idea in two lines: Some connectors introduce the cause (because, as, since), others introduce the result (so, therefore, as a result). The sentence can start with either part, but the connector must match the part it introduces.

🔵 Rules and concepts

  1. Because / as / since + clause (subject + verb) introduce the cause: The plants died because they had no water. As / since it was late, we went home.
  2. Because of / due to / thanks to + noun phrase: The match was cancelled because of the rain.
  3. So + clause introduces the result inside the same sentence, after a comma: It was cold, so we stayed in.
  4. Therefore / as a result / consequently / that is why usually start a new sentence and are followed by a comma: The sample was contaminated. Therefore, the test was repeated.
  5. Order is flexible: cause first (Because A, B) or result first (B because A). A comma is needed when the because-clause comes first.
  6. Never use "because" and "so" together to link the same two ideas.

🟢 Examples

  1. Join with "so": The water reached 100°C. It turned into steam. Answer: The water reached 100°C, so it turned into steam. Explanation: the first clause is the cause; "so" introduces the result after a comma.
  2. Rewrite with "because": The road was icy; therefore, the car skidded. Answer: The car skidded because the road was icy. Explanation: the result comes first, then "because" introduces the cause.
  3. Complete with "because of" or "because": The flight was delayed ... the fog. / We stayed inside ... it was raining. Answer: because of the fog / because it was raining. Explanation: "because of" + noun, "because" + clause.

🟠 Common BAC mistakes

  • Writing "because" + noun alone: "because the rain" instead of "because of the rain".
  • Using "so" to introduce a cause: "I stayed home so I was ill."
  • Doubling the connectors: "Because it rained, so we stayed in."
  • Forgetting the comma after "therefore" or "as a result" at the start of a sentence.

🟡 Quick review

  • Cause: because / as / since + clause; because of + noun.
  • Result: so (same sentence), therefore / as a result (new sentence + comma).
  • Result + because + cause, or Because + cause, + result.
  • One connector per link: never "because ... so".
  • Ask "why?" → cause; ask "what happened then?" → result.
