Le futur et le conditionnel

Objectif : Conjuguer et employer le futur et le conditionnel pour exprimer des prévisions, des hypothèses et des souhaits dans une nouvelle d'anticipation.

L'idée en deux lignes : Le futur présente un événement à venir comme certain ; le conditionnel le présente comme possible ou soumis à une condition. Les deux temps sont essentiels pour imaginer le monde de demain.

🔵 Règles et notions

  1. Le futur simple se forme sur l'infinitif + -ai, -as, -a, -ons, -ez, -ont : « parler → je parlerai ».
  2. Radicaux irréguliers à connaître : être → ser-, avoir → aur-, aller → ir-, faire → fer-, venir → viendr-, pouvoir → pourr-, voir → verr-.
  3. Le futur antérieur (aurai / serai + participe passé) marque une action future achevée avant une autre : « Quand nous aurons construit la base, nous partirons. »
  4. Le conditionnel présent = radical du futur + terminaisons de l'imparfait : « je serais », « nous pourrions ».
  5. Valeurs du conditionnel : hypothèse, souhait, politesse, information non confirmée, futur dans le passé.
  6. Le système hypothétique : si + présent → futur ; si + imparfait → conditionnel présent.
  7. Dans l'anticipation, le futur sert aux prévisions, le conditionnel aux scénarios imaginés.

🟢 Exemples

  1. « Si les glaciers fondent, la mer montera. » Explication : si + présent → futur : condition jugée réalisable.
  2. « Si les voitures volaient, les routes deviendraient inutiles. » Explication : si + imparfait → conditionnel : hypothèse imaginaire.
  3. « Le savant affirma que la machine fonctionnerait bientôt. » Explication : conditionnel = futur dans le passé, après un verbe au passé.

🟠 Erreurs fréquentes au BAC

  • Écrire « si + conditionnel » : on ne dit jamais « si j'aurais » mais « si j'avais ».
  • Confondre « je partirai » (futur) et « je partirais » (conditionnel) : vérifier avec « nous ».
  • Oublier le double « r » : « je pourrai », « je verrai », « je mourrai ».

🟡 À retenir

  • Futur = certitude à venir ; conditionnel = possibilité.
  • Conditionnel = radical du futur + terminaisons de l'imparfait.
  • Si + présent → futur ; si + imparfait → conditionnel.
  • Jamais de conditionnel après « si ».
