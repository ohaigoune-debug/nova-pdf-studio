معادلات ومتراجحات من الدرجة 1

الهدف: أن تحل معادلات ومتراجحات من الدرجة الأولى بمجهول واحد، وأن تدرس إشارة العبارة ax + b وتستعملها في حل معادلات ومتراجحات جداء.

الفكرة في سطرين: نعزل المجهول بعمليات تحافظ على المساواة أو المتباينة. والخطوة الحاسمة في المتراجحة: عند الضرب أو القسمة على عدد سالب ينقلب اتجاهها.

🔵 القواعد والمفاهيم

  1. معادلة من الدرجة الأولى: ax + b = 0 مع a ≠ 0، حلها الوحيد x = −b/a.
  2. خواص المساواة: يمكن إضافة العدد نفسه للطرفين أو ضربهما في العدد نفسه غير المعدوم.
  3. خواص المتباينة: الضرب في عدد موجب يحفظ الاتجاه، والضرب في عدد سالب يقلب الاتجاه.
  4. مجموعة الحلول لمتراجحة تُكتب على شكل مجال، مثل ]−∞;2[ أو [3;+∞[.
  5. إشارة ax + b: تأخذ إشارة a من أجل x > −b/a، وعكس إشارة a من أجل x < −b/a.
  6. معادلة جداء معدوم: A×B = 0 يعني A = 0 أو B = 0.

🟢 أمثلة تطبيقية

  1. حل 3x − 6 = 0. الحل: 3x = 6 ومنه x = 2.
  2. حل −2x + 4 > 0. الحل: −2x > −4، نقسم على −2 فينقلب الاتجاه: x < 2، إذن S = ]−∞;2[.
  3. حل (x − 1)(2x + 6) = 0 ثم (x − 1)(2x + 6) < 0. الحل: x = 1 أو x = −3. ومن جدول الإشارة يكون الجداء سالباً بين الجذرين: S = ]−3;1[.

🟠 أخطاء شائعة في البكالوريا

  • نسيان قلب اتجاه المتباينة عند القسمة على عدد سالب.
  • كتابة الحل عدداً واحداً بدل مجال في المتراجحة.
  • الخطأ في إغلاق المجال: المتراجحة الصارمة < تعطي قوساً مفتوحاً.
  • حل (x − 1)(2x + 6) < 0 بكتابة x − 1 < 0 و 2x + 6 < 0 دون جدول إشارة.

🟡 خلاصة للمراجعة السريعة

  • ax + b = 0 ⇐ x = −b/a.
  • عدد سالب في الضرب أو القسمة ⇐ ينقلب الاتجاه.
  • إشارة ax + b: «إشارة a على اليمين».
  • جداء معدوم ⇐ أحد عوامله معدوم.
  • متراجحة جداء ⇐ جدول إشارة.
