معادلات ومتراجحات من الدرجة 2

الهدف: أن تحلّ معادلة من الدرجة الثانية باستعمال المميّز، وأن تحلّل ثلاثي الحدود وتدرس إشارته لحلّ متراجحة.

الفكرة في سطرين: لكل ثلاثي حدود ax² + bx + c (a ≠ 0) عدد واحد يقرّر كل شيء: المميّز Δ = b² − 4ac. إشارته تعطي عدد الحلول، وإشارة a مع الجذور تعطي إشارة العبارة.

🔵 القواعد والمفاهيم

  1. المميّز: Δ = b² − 4ac للمعادلة ax² + bx + c = 0 حيث a ≠ 0.
  2. إذا كان Δ > 0 فللمعادلة حلّان: x₁ = (−b − √Δ)/(2a) و x₂ = (−b + √Δ)/(2a).
  3. إذا كان Δ = 0 فلها حلّ مضاعف x₀ = −b/(2a)، وإذا كان Δ < 0 فلا حلول لها في ℝ.
  4. التحليل: إذا Δ > 0 فإن ax² + bx + c = a(x − x₁)(x − x₂)، وإذا Δ = 0 فهو a(x − x₀)².
  5. الإشارة: ثلاثي الحدود له إشارة a خارج الجذرين، وعكس إشارة a بينهما؛ وإذا Δ < 0 فله دائماً إشارة a.
  6. المجموع والجداء: x₁ + x₂ = −b/a و x₁ × x₂ = c/a.

🟢 أمثلة تطبيقية

  1. حلّ x² − 5x + 6 = 0. الحل: Δ = 25 − 24 = 1، إذن x₁ = (5 − 1)/2 = 2 و x₂ = (5 + 1)/2 = 3. تحقّق: 2 + 3 = 5 و 2 × 3 = 6.
  2. حلّ المتراجحة x² − 5x + 6 < 0. الحل: a = 1 > 0، فالعبارة سالبة بين الجذرين: S = ]2 ; 3[.
  3. ادرس إشارة 2x² + x + 1. الحل: Δ = 1 − 8 = −7 < 0، إذن العبارة لها إشارة a = 2، فهي موجبة تماماً من أجل كل x حقيقي.

🟠 أخطاء شائعة في البكالوريا

  • نسيان إشارة b عند حساب Δ أو −b: مع b = −5 يكون −b = 5 و b² = 25.
  • كتابة «لا حلول» إذا Δ = 0، بينما يوجد حلّ مضاعف.
  • نسيان المعامل a عند التحليل: 2x² − 2 = 2(x − 1)(x + 1) وليس (x − 1)(x + 1).
  • عكس الإشارة بين الجذرين وخارجهما عندما يكون a سالباً.

🟡 خلاصة للمراجعة السريعة

  • احسب Δ = b² − 4ac أولاً دائماً.
  • Δ > 0: جذران، Δ = 0: جذر مضاعف، Δ < 0: لا جذور.
  • الإشارة: «إشارة a خارج الجذرين».
  • للتحقق: المجموع −b/a والجداء c/a.
  • المتراجحة تُحلّ بجدول إشارة ثلاثي الحدود.
