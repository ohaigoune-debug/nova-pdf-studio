الزوايا الموجهة لشعاعين

الهدف: أن تعرّف الزاوية الموجهة لشعاعين وقياساتها بتقريب 2π، وأن تستعمل علاقة شال وخواص الزوايا الموجهة وتعيّن القياس الرئيسي.

الفكرة في سطرين: نوجّه المستوي بجعل الدوران عكس عقارب الساعة هو الاتجاه الموجب، فنقيس الزاوية من الشعاع الأول إلى الثاني. القياس معرّف بتقريب مضاعفات 2π.

🔵 القواعد والمفاهيم

  1. الاتجاه المباشر (الموجب) عكس عقارب الساعة.
  2. إذا كان θ قياسًا للزاوية (u ; v) فكل عدد θ + 2kπ (k صحيح) قياس لها، ونكتب (u ; v) = θ [2π].
  3. القياس الرئيسي هو القياس الوحيد في المجال ]−π ; π].
  4. علاقة شال: (u ; v) + (v ; w) = (u ; w) [2π].
  5. (v ; u) = −(u ; v) [2π] ، و(−u ; v) = (u ; v) + π [2π].
  6. إذا كان k > 0 فإن (u ; kv) = (u ; v) [2π] ، وإذا كان k < 0 فإن (u ; kv) = (u ; v) + π [2π].
  7. الشعاعان لهما نفس الاتجاه إذا كان القياس 0 [2π] ، ومتعاكسان إذا كان π [2π].

🟢 أمثلة تطبيقية

  1. القياس الرئيسي لـ 7π/3. الحل: 7π/3 − 2π = π/3 وهو في ]−π ; π] ، فالقياس الرئيسي π/3.
  2. القياس الرئيسي لـ −19π/4. الحل: نضيف 4π = 16π/4 فنجد −3π/4 وهو في المجال المطلوب.
  3. إذا كان (u ; v) = π/3 [2π] و(v ; w) = π/2 [2π]. الحل: (u ; w) = π/3 + π/2 = 5π/6 [2π] حسب علاقة شال.

🟠 أخطاء شائعة في البكالوريا

  • إعطاء قياس خارج المجال ]−π ; π] عند طلب القياس الرئيسي.
  • نسيان كتابة [2π] بعد المساواة بين الزوايا.
  • الخطأ في إشارة القياس عند تبديل ترتيب الشعاعين.
  • الخلط بين الزاوية الهندسية (موجبة دائمًا) والزاوية الموجهة التي لها إشارة.

🟡 خلاصة للمراجعة السريعة

  • القياس معرّف بتقريب 2π.
  • القياس الرئيسي في ]−π ; π].
  • شال: (u ; v) + (v ; w) = (u ; w) [2π].
  • تبديل الترتيب يغيّر الإشارة، وعكس شعاع يضيف π.
