Conditional type 1

Objective: To express real and possible situations in the future and their likely results using the first conditional.

The idea in two lines: The first conditional links a possible condition to its probable result: if + present simple, will + base form. We use it for predictions, warnings, promises and advice.

🔵 Rules and concepts

  1. Structure: If + present simple, will + base form: If we work together, we will build peace.
  2. Order: the main clause can come first with no comma: We will build peace if we work together.
  3. Meaning: a real or likely situation in the present or future.
  4. Unless = if … not: Unless we stop wars, many people will suffer.
  5. Other forms in the result: a modal (can, may, should) or an imperative: If you see violence, call for help.
  6. No will in the if clause: the condition is always in the present.

🟢 Examples

  1. Complete: "If countries (respect) each other, there (be) less conflict." Answer: If countries respect each other, there will be less conflict.
  2. Join with unless: "If you don't apologise, he won't forgive you." Answer: Unless you apologise, he won't forgive you. Explanation: unless already contains the negative.
  3. Correct: "If she will come, we will discuss the problem." Answer: If she comes, we will discuss the problem.

🟠 Common BAC mistakes

  • Putting will in the if clause.
  • Using a double negative with unless: Unless you don't study ✗.
  • Forgetting the third-person -s in the if clause: If he come ✗ → If he comes ✓.
  • Confusing type 1 (likely) with type 2 (if + past, would: imaginary).

🟡 Quick review

  • If + present, will + verb.
  • Real, possible future result.
  • Unless = if … not.
  • Comma when the if clause starts the sentence.
  • No will after if.
