L'expression du but

Objectif : Reconnaître et employer les différents moyens d'exprimer le but (conjonction + subjonctif, préposition + infinitif, groupe nominal) pour justifier une action dans un texte argumentatif.

L'idée en deux lignes : Exprimer le but, c'est indiquer l'objectif que l'on cherche à atteindre (ou à éviter). On utilise pour que, afin que + subjonctif quand les sujets sont différents, et pour, afin de + infinitif quand le sujet est le même.

🔵 Règles et notions

  1. Le but est l'objectif visé par une action ; il répond à la question « dans quel but ? pourquoi faire ? ». Contrairement à la cause, il se situe dans l'avenir et n'est pas encore réalisé.
  2. Les conjonctions de subordination pour que, afin que, de sorte que, de manière que introduisent une proposition subordonnée de but dont le verbe est au subjonctif.
  3. Le but négatif (ce que l'on veut éviter) s'exprime par de peur que, de crainte que + subjonctif, ou pour que… ne… pas.
  4. Quand les deux verbes ont le même sujet, on emploie une préposition suivie de l'infinitif : pour, afin de, en vue de, dans le but de, de peur de, de crainte de.
  5. Le but peut aussi s'exprimer par un groupe nominal : pour la réussite, en vue de l'examen, dans le but d'une victoire.
  6. Certains verbes expriment le but par leur sens : viser à, chercher à, avoir pour but de. Dans l'argumentation, le but sert à justifier une proposition.

🟢 Exemples

  1. Relier les deux phrases : « Les parents économisent. Leurs enfants poursuivent leurs études. » Solution : « Les parents économisent pour que leurs enfants poursuivent leurs études. » Explication : sujets différents → pour que + subjonctif.
  2. Relier : « Je fais du sport. Je reste en bonne santé. » Solution : « Je fais du sport afin de rester en bonne santé. » Explication : même sujet → préposition + infinitif.
  3. Exprimer un but négatif : « Il prend des notes. Il ne veut pas oublier la leçon. » Solution : « Il prend des notes de peur d'oublier la leçon. »

🟠 Erreurs fréquentes au BEM

  • Mettre l'indicatif après pour que : « pour que tu viens » au lieu de « pour que tu viennes ».
  • Employer pour que avec le même sujet : « Je travaille pour que je réussisse » est maladroit ; on écrit « pour réussir ».
  • Confondre but et cause : « parce que » explique ce qui s'est déjà passé ; « pour que » annonce ce que l'on veut obtenir.
  • Confondre de sorte que + subjonctif (but) et de sorte que + indicatif (conséquence réalisée).

🟡 À retenir

  • But = objectif visé, non encore réalisé : « dans quel but ? ».
  • Sujets différents : pour que, afin que, de peur que + subjonctif.
  • Même sujet : pour, afin de, en vue de, de peur de + infinitif.
  • Groupe nominal : pour / en vue de + nom.
  • Verbes de but : viser à, chercher à, avoir pour but de.
