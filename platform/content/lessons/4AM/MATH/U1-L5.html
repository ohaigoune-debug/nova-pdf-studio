الجذور التربيعية

الهدف: أن تعرّف الجذر التربيعي لعدد موجب وتحسب جذور المربعات التامة، وأن تستعمل خواص الجداء والقسمة لتبسيط عبارات تحوي جذورًا وحلّ معادلات من الشكل x2 = a.

الفكرة في سطرين: الجذر التربيعي للعدد الموجب a هو العدد الموجب الذي مربعه a؛ فهو طول ضلع مربع مساحته a. الجذر يتوافق مع الضرب والقسمة (√(ab) = √a × √b) لكنه لا يتوافق أبدًا مع الجمع والطرح.

🔵 القواعد والمفاهيم

  1. التعريف: إذا كان a ≥ 0 فإن √a هو العدد الموجب الوحيد الذي مربعه a، أي (√a)2 = a. لا يوجد جذر تربيعي لعدد سالب.
  2. المربعات التامة: √0 = 0، √1 = 1، √4 = 2، √9 = 3، √16 = 4، √25 = 5، √36 = 6، √49 = 7، √64 = 8، √81 = 9، √100 = 10، √144 = 12.
  3. جذر مربع: √(a2) = a إذا كان a ≥ 0، مثلًا √(72) = 7.
  4. جذر جداء وجذر قسمة: √(a × b) = √a × √b و √(a/b) = √a / √b مع a ≥ 0 و b > 0.
  5. تحذير: √(a + b) ≠ √a + √b؛ مثلًا √(9 + 16) = √25 = 5 بينما √9 + √16 = 7.
  6. التبسيط: نكتب العدد تحت الجذر جداءً لمربع تام في عدد آخر: √50 = √(25 × 2) = 5√2.
  7. المعادلة x2 = a: إذا كان a > 0 فلها حلّان √a و −√a؛ إذا كان a = 0 فحلّها 0؛ وإذا كان a < 0 فليس لها حل.

🟢 أمثلة تطبيقية

  1. بسّط A = √12 + √75. الحل: √12 = √(4 × 3) = 2√3 و √75 = √(25 × 3) = 5√3، فيكون A = 2√3 + 5√3 = 7√3. التحقق بالآلة: √12 + √75 ≈ 3,46 + 8,66 = 12,12 و 7√3 ≈ 12,12.
  2. احسب B = √8 × √2 و C = (√5 + 1)2. الحل: B = √(8 × 2) = √16 = 4. و C = (√5)2 + 2 × √5 × 1 + 12 = 5 + 2√5 + 1 = 6 + 2√5.
  3. مثلث قائم ضلعا قائمته 2 cm و 3 cm، احسب وتره، ثم حلّ المعادلة x2 = 16. الحل: بنظرية فيثاغورس الوتر = √(22 + 32) = √(4 + 9) = √13 ≈ 3,6 cm. وحلّا المعادلة هما 4 و −4 لأن 42 = (−4)2 = 16.

🟠 أخطاء شائعة في شهادة التعليم المتوسط BEM

  • توزيع الجذر على الجمع: كتابة √(a + b) = √a + √b؛ الجذر يتوافق مع الضرب والقسمة فقط.
  • الاكتفاء بالحل الموجب للمعادلة x2 = 16 ونسيان الحل −4.
  • كتابة 2√3 + 5√2 = 7√5؛ لا نجمع إلا الجذور المتشابهة (نفس العدد تحت الجذر).
  • الخلط بين √(a2) و (√a)2 أو كتابة √50 = 25√2 بدل 5√2 عند استخراج المربع التام.

🟡 خلاصة للمراجعة السريعة

  • √a (مع a ≥ 0) هو العدد الموجب الذي مربعه a.
  • √(ab) = √a √b و √(a/b) = √a/√b، لكن √(a + b) ≠ √a + √b.
  • للتبسيط: أخرج أكبر مربع تام من تحت الجذر.
  • x2 = a (a > 0) ⇒ x = √a أو x = −√a.
  • احفظ المربعات التامة حتى 144 لتسريع الحساب.
