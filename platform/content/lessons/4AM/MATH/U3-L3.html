الدالة التآلفية

الهدف: أن تتعرّف على الدالة التآلفية f(x) = ax + b، وتميّز معاملها a عن ترتيبها عند المبدأ b، وأن تحسب صورة وسابقة، وأن تعيّن الدالة انطلاقًا من قيمتين معلومتين.

الفكرة في سطرين: الدالة التآلفية تضرب العدد x في a ثم تضيف عددًا ثابتًا b. ليست تناسبية (إلا إذا كان b = 0)، لكن الزيادات فيها تناسبية: إذا زاد x بمقدار معيّن زادت صورته بـ a ضعف هذا المقدار.

🔵 القواعد والمفاهيم

  1. تعريف: a و b عددان معلومان. الدالة التآلفية هي f: x ↦ ax + b؛ a هو معامل الدالة و b هو الترتيب عند المبدأ لأن f(0) = b.
  2. حالتان خاصتان: إذا كان b = 0 فالدالة خطية؛ وإذا كان a = 0 فالدالة ثابتة.
  3. الصورة: نعوّض x في العبارة. السابقة: لإيجاد سابقة y نحل المعادلة ax + b = y أي x = (y − b)/a.
  4. خاصية الزيادات: لكل عددين مختلفين x1 و x2: f(x2) − f(x1) = a × (x2 − x1).
  5. تعيين الدالة من قيمتين: a = (f(x2) − f(x1)) ÷ (x2 − x1)، ثم b = f(x1) − a × x1.
  6. تمثيلها البياني مستقيم يقطع محور التراتيب في النقطة ذات الترتيب b (الدرس القادم).

🟢 أمثلة تطبيقية

  1. f(x) = 2x − 3. الحل: f(4) = 8 − 3 = 5، و f(0) = −3 (الترتيب عند المبدأ). سابقة العدد 7: نحل 2x − 3 = 7، فيكون x = 5.
  2. g دالة تآلفية بحيث g(1) = 5 و g(3) = 11. الحل: a = (11 − 5)/(3 − 1) = 3، ثم b = g(1) − 3 × 1 = 2. إذن g(x) = 3x + 2. تحقّق: g(3) = 9 + 2 = 11 صحيح.
  3. سيارة أجرة تتقاضى 50 دج عند الانطلاق و 20 دج عن كل كيلومتر. الحل: ثمن x كلم هو C(x) = 20x + 50 (a = 20 و b = 50)؛ C(8) = 160 + 50 = 210 دج.

🟠 أخطاء شائعة في شهادة التعليم المتوسط BEM

  • معاملة الدالة التآلفية كتناسبية وحساب f(6) بمضاعفة f(3).
  • عكس ترتيب الفرقين في حساب a (قسمة فرق x على فرق f(x)).
  • الخلط بين a و b: b هو f(0) وليس المعامل.
  • نسيان نقل b إلى الطرف الآخر عند حل المعادلة لإيجاد السابقة.

🟡 خلاصة للمراجعة السريعة

  • تآلفية: f(x) = ax + b، و f(0) = b.
  • b = 0 ⇒ خطية؛ a = 0 ⇒ ثابتة.
  • سابقة y: x = (y − b)/a.
  • من قيمتين: a = فرق الصور ÷ فرق الأعداد، ثم b = f(x1) − a x1.
  • الزيادات متناسبة مع المعامل a.
