حل المعادلات في C

الهدف: أن تحل في مجموعة الأعداد المركبة C معادلات من الدرجة الأولى ومن الدرجة الثانية بمعاملات حقيقية، ومعادلات كثيرات حدود يُعرف أحد جذورها.

الفكرة في سطرين: في C يصبح للعدد السالب جذران تربيعيان، فكل معادلة من الدرجة الثانية لها حلول حتى لو كان المميز سالباً. أما المعادلات التي تحوي z و z̄ فنحلها بكتابة z = x + iy ثم المطابقة.

🔵 القواعد والمفاهيم

  1. المعادلة z² = a مع a حقيقي سالب: حلاها i√−a و −i√−a.
  2. المميز: لمعادلة az² + bz + c = 0 بمعاملات حقيقية نحسب Δ = b² − 4ac.
  3. إذا كان Δ < 0 فالحلان مترافقان: z = (−b ± i√−Δ)/2a.
  4. معادلة تحوي z̄: نضع z = x + iy ثم نطابق الجزأين الحقيقي والتخيلي.
  5. كثير حدود له جذر معلوم z₀: إذا كان P(z₀) = 0 فإن P(z) = (z − z₀)Q(z)، ونجد Q بالمطابقة أو بالقسمة.
  6. التحقق: مجموع الحلين −b/a وجداؤهما c/a.

🟢 أمثلة تطبيقية

  1. حل z² − 2z + 5 = 0. الحل: Δ = 4 − 20 = −16، إذن z = (2 ± 4i)/2، أي z₁ = 1 + 2i و z₂ = 1 − 2i. تحقق: المجموع 2 والجداء 1 + 4 = 5.
  2. حل z² + 9 = 0. الحل: z² = −9 إذن z = 3i أو z = −3i.
  3. حل z + 2z̄ = 3 − i. الحل: بوضع z = x + iy نجد 3x − iy = 3 − i، إذن x = 1 و y = 1، ومنه z = 1 + i.

🟠 أخطاء شائعة في البكالوريا

  • كتابة √−16 في الحل النهائي بدل 4i.
  • القول «المعادلة لا تقبل حلولاً» عندما Δ < 0: هذا صحيح في R فقط لا في C.
  • نسيان أن مرافق x + iy هو x − iy عند المطابقة، فيُخطأ في إشارة الجزء التخيلي.
  • عدم التحقق من P(z₀) = 0 قبل التحليل.

🟡 خلاصة للمراجعة السريعة

  • Δ < 0 ⇐ حلان مترافقان (−b ± i√−Δ)/2a.
  • z² = −k² ⇐ z = ±ik.
  • معادلة فيها z̄ ⇐ z = x + iy ثم مطابقة.
  • جذر معلوم ⇐ تحليل (z − z₀)Q(z).
  • تحقق دائماً بالمجموع والجداء.
