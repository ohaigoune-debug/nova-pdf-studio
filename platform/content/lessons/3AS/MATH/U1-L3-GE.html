الدوال الأسية واللوغاريتمية

الهدف: أن توظّف خواص الدالتين الأسية exp واللوغاريتمية ln في حل المعادلات والمتراجحات وحساب المشتقات والنهايات.

الفكرة في سطرين: الدالة ln هي الدالة العكسية للدالة exp: eˣ = y ⇔ x = ln y مع y > 0. لذلك منحناهما متناظران بالنسبة إلى المستقيم y = x.

🔵 القواعد والمفاهيم

  1. الدالة الأسية: معرّفة على ℝ، eˣ > 0، e⁰ = 1، eᵃ⁺ᵇ = eᵃ × eᵇ، و(eᵘ)′ = u′eᵘ.
  2. نهايات exp: lim eˣ = 0 لما x → −∞ وlim eˣ = +∞ لما x → +∞.
  3. الدالة اللوغاريتمية: معرّفة على ]0 ; +∞[، ln 1 = 0، ln e = 1، و(ln u)′ = u′/u مع u > 0.
  4. الخواص الجبرية: ln(ab) = ln a + ln b، ln(a/b) = ln a − ln b، ln(aⁿ) = n ln a.
  5. نهايات ln: lim ln x = −∞ لما x → 0⁺ و+∞ لما x → +∞.
  6. التزايد المقارن: lim eˣ/x = +∞ وlim (ln x)/x = 0 لما x → +∞.
  7. الرتابة: الدالتان متزايدتان تماماً، لذا eᵃ < eᵇ ⇔ a < b وln a < ln b ⇔ a < b مع a, b > 0.

🟢 أمثلة تطبيقية

  1. حل e²ˣ⁻¹ = 1. الحل: e²ˣ⁻¹ = e⁰ إذن 2x − 1 = 0 ومنه x = 1/2.
  2. حل ln(x − 1) = ln 3. الحل: الشرط x > 1؛ x − 1 = 3 أي x = 4 وهو يحقق الشرط.
  3. مشتقة f(x) = x ln x على ]0 ; +∞[. الحل: f′(x) = 1 × ln x + x × (1/x) = ln x + 1.

🟠 أخطاء شائعة في البكالوريا

  • نسيان شرط الوجود u(x) > 0 قبل حل معادلة فيها ln.
  • كتابة ln(a + b) = ln a + ln b وهي خاطئة.
  • كتابة (eᵘ)′ = eᵘ بنسيان العامل u′.
  • الاعتقاد أن eˣ قد تنعدم أو تكون سالبة.

🟡 خلاصة للمراجعة السريعة

  • eˣ > 0 دائماً، وln معرّفة على الموجبات تماماً فقط.
  • eˣ = y ⇔ x = ln y.
  • ln تحوّل الجداء إلى مجموع.
  • (eᵘ)′ = u′eᵘ و(ln u)′ = u′/u.
  • الأسية «تغلب» x، وx «تغلب» ln عند +∞.
