الأوضاع النسبية والمسافة

الهدف: أن تدرس الوضع النسبي لمستويين ولمستقيم ومستو باستعمال الأشعة الناظمية وأشعة التوجيه، وأن تحسب المسافة بين نقطة ومستو.

الفكرة في سطرين: الأوضاع النسبية تُقرأ من الأشعة: ارتباط الناظمين خطياً، أو انعدام جداء شعاع التوجيه والناظم. والمسافة بين نقطة ومستو هي طول العمود النازل منها عليه.

🔵 القواعد والمفاهيم

  1. مستويان ناظماهما n→ وn'→: إذا كانا مرتبطين خطياً فالمستويان متوازيان (تماماً أو منطبقان)، وإلا فهما متقاطعان وفق مستقيم.
  2. تعامد مستويين: n→ · n'→ = 0.
  3. مستقيم ومستو: إذا كان u→ · n→ = 0 فالمستقيم يوازي المستوي (محتوى فيه أو موازٍ تماماً)، وإلا فهما متقاطعان في نقطة واحدة.
  4. مستقيم عمودي على مستو: شعاع توجيهه u مرتبط خطياً بالناظم n.
  5. مستقيمان في الفضاء: إما من نفس المستوي (متوازيان أو متقاطعان) وإما ليسا من نفس المستوي.
  6. المسافة بين A(x0 ; y0 ; z0) والمستوي ax + by + cz + d = 0: |ax0 + by0 + cz0 + d| / √(a² + b² + c²).

🟢 أمثلة تطبيقية

  1. المسافة بين A(1 ; 2 ; 3) والمستوي 2x − y + 2z − 3 = 0. الحل: |2 − 2 + 6 − 3| / √(4 + 1 + 4) = 3/3 = 1.
  2. المستقيم x = 1 + t ، y = 2t ، z = −1 + t والمستوي x + y − 3z − 1 = 0. الحل: u→(1 ; 2 ; 1) · n→(1 ; 1 ; −3) = 1 + 2 − 3 = 0؛ والنقطة (1 ; 0 ; −1) تعطي 1 + 0 + 3 − 1 = 3 ≠ 0: المستقيم يوازي المستوي تماماً.
  3. المستقيم x = t ، y = 1 + t ، z = 2t والمستوي x + y + z − 5 = 0. الحل: t + (1 + t) + 2t − 5 = 4t − 4 = 0 إذن t = 1، ونقطة التقاطع (1 ; 2 ; 2).

🟠 أخطاء شائعة في البكالوريا

  • استنتاج أن المستقيم محتوى في المستوي من u→ · n→ = 0 وحده دون اختبار نقطة منه.
  • نسيان القيمة المطلقة أو الجذر في دستور المسافة.
  • الخلط بين «مستقيمان غير متقاطعين» و«متوازيان»: في الفضاء قد لا يكونان من نفس المستوي.

🟡 خلاصة للمراجعة السريعة

  • ناظمان مرتبطان خطياً ⇐ مستويان متوازيان.
  • u→ · n→ = 0 ⇐ مستقيم يوازي المستوي؛ وإلا تقاطع في نقطة.
  • المسافة = |ax0 + by0 + cz0 + d| / √(a² + b² + c²).
