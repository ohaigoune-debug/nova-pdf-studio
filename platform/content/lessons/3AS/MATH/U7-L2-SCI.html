الأوضاع النسبية والمسافة

الهدف: أن تدرس الوضع النسبي لمستقيم ومستو ولمستويين، وأن تحسب بعد نقطة عن مستو.

الفكرة في سطرين: نقارن شعاع توجيه المستقيم بالشعاع الناظمي للمستوي: إن كانا متعامدين فالمستقيم يوازي المستوي أو محتوى فيه، وإلا فهو يقطعه في نقطة. والبعد عن مستو يُحسب بدستور واحد مباشر.

🔵 القواعد والمفاهيم

  1. التمثيل الوسيطي لمستقيم يشمل A(x₀, y₀, z₀) وشعاع توجيهه u(α, β, γ): x = x₀ + αt ، y = y₀ + βt ، z = z₀ + γt.
  2. مستقيم ومستو: إذا u · n ≠ 0 فهما متقاطعان في نقطة؛ إذا u · n = 0 فالمستقيم موازٍ تماماً أو محتوى في المستوي.
  3. مستويان: إذا كان الناظمان مرتبطين خطياً فالمستويان متوازيان (أو منطبقان)، وإلا فهما متقاطعان وفق مستقيم.
  4. التعامد: المستويان متعامدان إذا n · n' = 0.
  5. بعد نقطة عن مستو ax + by + cz + d = 0: d(A, P) = |ax₀ + by₀ + cz₀ + d| / √(a² + b² + c²).

🟢 أمثلة تطبيقية

  1. احسب بعد A(1, 1, 1) عن x + 2y + 2z − 2 = 0. الحل: |1 + 2 + 2 − 2| / √(1 + 4 + 4) = 3/3 = 1.
  2. (D): x = 1 + t ، y = 2 − t ، z = 3t و (P): x + y − 1 = 0. الحل: u(1, −1, 3) و n(1, 1, 0)، u · n = 1 − 1 + 0 = 0. النقطة (1, 2, 0) تعطي 1 + 2 − 1 = 2 ≠ 0، إذن (D) موازٍ تماماً لـ (P).
  3. تقاطع (D): x = t ، y = 1 + t ، z = 2t مع x + y + z − 5 = 0. الحل: t + 1 + t + 2t − 5 = 0 أي 4t = 4 و t = 1، فنقطة التقاطع (1, 2, 2). تحقق: 1 + 2 + 2 − 5 = 0.

🟠 أخطاء شائعة في البكالوريا

  • الاستنتاج من u · n = 0 أن المستقيم يقطع المستوي؛ الصحيح أنه موازٍ أو محتوى.
  • نسيان القيمة المطلقة في البسط أو الجذر في المقام في دستور البعد.
  • التوقف عند u · n = 0 دون تعويض نقطة للفصل بين التوازي التام والاحتواء.

🟡 خلاصة للمراجعة السريعة

  • u · n ≠ 0 ⇐ تقاطع في نقطة.
  • u · n = 0 ⇐ توازٍ أو احتواء (نعوض نقطة).
  • ناظمان مرتبطان ⇐ مستويان متوازيان.
  • البعد: |ax₀ + by₀ + cz₀ + d| / √(a² + b² + c²).
