الدالة الأسية واللوغاريتم النيبيري

الهدف: أن تتحكم في خواص الدالة الأسية والدالة اللوغاريتمية النيبيرية، وأن تستعملها في حل المعادلات والمتراجحات وحساب المشتقات والنهايات.

الفكرة في سطرين: الدالة الأسية هي الدالة الوحيدة التي تساوي مشتقتها وتأخذ القيمة 1 عند 0. واللوغاريتم النيبيري دالتها العكسية، فمنحناهما متناظران بالنسبة إلى المستقيم y = x.

🔵 القواعد والمفاهيم

  1. الدالة الأسية: معرّفة على ℝ، موجبة تماماً، (ex)' = ex وe0 = 1، وea + b = ea × eb.
  2. اللوغاريتم النيبيري: معرّف على ]0 ; +∞[، (ln x)' = 1/x وln 1 = 0 وln e = 1.
  3. العلاقة العكسية: eln x = x لكل x > 0، وln(ex) = x لكل x حقيقي.
  4. خواص جبرية: ln(ab) = ln a + ln b وln(a/b) = ln a − ln b وln(an) = n ln a مع a, b > 0.
  5. التكافؤات: ea = eb ⇔ a = b، وln a < ln b ⇔ a < b مع a, b > 0.
  6. نهايات مرجعية: عند +∞: ex/x → +∞ وln x / x → 0؛ وعند −∞: x ex → 0؛ وعند 0+: x ln x → 0.

🟢 أمثلة تطبيقية

  1. حل e2x − 1 = e3. الحل: 2x − 1 = 3 إذن x = 2.
  2. حل ln(x − 2) ≤ 0. الحل: الشرط x > 2، وln(x − 2) ≤ ln 1 يعني x − 2 ≤ 1، فمجموعة الحلول ]2 ; 3].
  3. اشتق f(x) = x ex. الحل: مشتقة جداء: f'(x) = ex + x ex = (x + 1)ex، وإشارتها إشارة x + 1.

🟠 أخطاء شائعة في البكالوريا

  • حل معادلة لوغاريتمية دون تحديد شروط الوجود أولاً ثم دون التحقق من الحلول.
  • كتابة ln(a + b) = ln a + ln b: هذه خاطئة.
  • نسيان أن ex > 0 دائماً، فلا يحتاج دراسة إشارة.
  • الخلط بين (eu)' = u' eu و(ln u)' = u'/u.

🟡 خلاصة للمراجعة السريعة

  • exp' = exp وex > 0.
  • ln معرّف على ]0 ; +∞[ فقط.
  • الجداء داخل ln يصبح مجموعاً.
  • الأسية تتغلب على كثيرات الحدود عند +∞، وهذه تتغلب على اللوغاريتم.
