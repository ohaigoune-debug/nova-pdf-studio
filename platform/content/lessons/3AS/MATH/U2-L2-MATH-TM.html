المعادلات التفاضلية y'=ay+b

الهدف: أن تحل معادلة تفاضلية من الشكل y′ = ay + b، وأن تعيّن الحل الوحيد الذي يحقق شرطاً ابتدائياً معطى.

الفكرة في سطرين: المعادلة التفاضلية علاقة بين دالة مجهولة ومشتقتها. حلول y′ = ay هي دوال أسية، ونضيف إليها حلاً ثابتاً لنحصل على حلول y′ = ay + b.

🔵 القواعد والمفاهيم

  1. المعادلة y′ = ay: حلولها الدوال x ↦ Ceax حيث C عدد حقيقي كيفي.
  2. الحل الثابت: إذا كان a ≠ 0 فالدالة الثابتة y = −b/a حل خاص للمعادلة y′ = ay + b.
  3. الحل العام: حلول y′ = ay + b هي y = Ceax − b/a.
  4. الشرط الابتدائي: من أجل x₀ وy₀ معطيين يوجد حل وحيد يحقق y(x₀) = y₀.
  5. حالة a = 0: المعادلة y′ = b حلولها y = bx + C.
  6. السلوك عند +∞: إذا كان a < 0 تؤول كل الحلول إلى −b/a.

🟢 أمثلة تطبيقية

  1. حل y′ = 2y مع y(0) = 3. الحل: y = Ce2x وy(0) = C = 3، إذن y = 3e2x.
  2. حل y′ = −y + 4 مع y(0) = 1. الحل: −b/a = 4 فـ y = Ce−x + 4، وC + 4 = 1 أي C = −3. التحقق: y′ = 3e−x و−y + 4 = 3e−x.
  3. حل y′ = 3y − 6 مع y(0) = 2. الحل: y = Ce3x + 2 وC + 2 = 2، إذن C = 0 والحل هو الدالة الثابتة y = 2.

🟠 أخطاء شائعة في البكالوريا

  • كتابة الحل الخاص b/a بدل −b/a.
  • تعيين C قبل إضافة الحل الخاص، فيُستعمل الشرط الابتدائي في Ceax وحدها.
  • نسيان التحقق من الحل بالتعويض في المعادلة.
  • الخلط بين eax وex + a.

🟡 خلاصة للمراجعة السريعة

  • y′ = ay ⇒ y = Ceax.
  • y′ = ay + b ⇒ y = Ceax − b/a.
  • الشرط الابتدائي يعيّن C بشكل وحيد.
  • تحقّق دائماً بالتعويض.
