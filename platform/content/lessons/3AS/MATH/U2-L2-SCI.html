المعادلات التفاضلية y'=ay+b

الهدف: أن تحل المعادلة التفاضلية y' = ay + b، وأن تعيّن الحل الخاص الذي يحقق شرطاً ابتدائياً معطى.

الفكرة في سطرين: المعادلة التفاضلية مجهولها دالة. حلول y' = ay + b عائلة دوال أسية تقترب أو تبتعد عن حل ثابت، والشرط الابتدائي يختار منها حلاً واحداً.

🔵 القواعد والمفاهيم

  1. المعادلة y' = ay (a حقيقي): حلولها الدوال x ↦ C eax حيث C ثابت حقيقي كيفي.
  2. المعادلة y' = ay + b مع a ≠ 0: حلولها x ↦ C eax − b/a.
  3. الحل الثابت هو y = −b/a، ونحصل عليه بوضع y' = 0.
  4. الشرط الابتدائي: من أجل x0 وy0 معطيين يوجد حل وحيد يحقق y(x0) = y0.
  5. السلوك: إذا كان a < 0 فكل الحلول تؤول إلى −b/a عند +∞؛ وإذا كان a > 0 فهي تبتعد عنه ما عدا الحل الثابت.
  6. التحقق: نعوّض الحل المقترح في المعادلة ونتأكد من تساوي الطرفين.

🟢 أمثلة تطبيقية

  1. حل y' = 2y مع y(0) = 3. الحل: y = C e2x وy(0) = C = 3، إذن y = 3e2x.
  2. حل y' = −2y + 4 مع y(0) = 0. الحل: −b/a = −4/(−2) = 2، فالحلول y = C e−2x + 2. الشرط يعطي C + 2 = 0 أي C = −2، إذن y = 2 − 2e−2x. تحقق: y' = 4e−2x و−2y + 4 = 4e−2x.
  3. حل y' = 3y − 6 مع y(0) = 5. الحل: −b/a = 6/3 = 2، y = C e3x + 2 وC + 2 = 5 إذن y = 3e3x + 2.

🟠 أخطاء شائعة في البكالوريا

  • كتابة الحل الثابت b/a بدل −b/a (خطأ في الإشارة).
  • نسيان الثابت C أو تعيينه قبل إضافة الحل الثابت.
  • الخلط بين eax وex/a.
  • إهمال وضع المعادلة على الشكل y' = ay + b قبل قراءة a وb، مثل 2y' − y = 4 التي تصبح y' = 0,5y + 2.

🟡 خلاصة للمراجعة السريعة

  • y' = ay ⇒ y = C eax.
  • y' = ay + b ⇒ y = C eax − b/a.
  • الشرط الابتدائي يعيّن C فيصبح الحل وحيداً.
  • تحقق دائماً بالتعويض في المعادلة.
