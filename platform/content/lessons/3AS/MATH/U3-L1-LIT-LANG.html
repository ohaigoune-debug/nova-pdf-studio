الدالة التآلفية ودالة الدرجة الثانية

الهدف: أن تتعرف على الدالة التآلفية ودالة الدرجة الثانية، وأن تحدد اتجاه تغيرهما وتمثّلهما بيانياً انطلاقاً من عبارتيهما.

الفكرة في سطرين: منحنى الدالة التآلفية مستقيم يحدد ميله اتجاه تغيرها. منحنى دالة الدرجة الثانية قطع مكافئ له رأس ومحور تناظر، وإشارة معامل x2 تحدد اتجاه فتحته.

🔵 القواعد والمفاهيم

  1. الدالة التآلفية: f(x) = ax + b معرّفة على ℝ؛ a هو المعامل الموجّه وb هو الترتيب إلى المبدأ.
  2. إذا كان a > 0 فـ f متزايدة تماماً، وإذا كان a < 0 فهي متناقصة تماماً، وa = 0 تعني دالة ثابتة.
  3. إشارة ax + b: تنعدم عند x = −b ÷ a وتأخذ إشارة a على يمين هذا العدد.
  4. دالة الدرجة الثانية: g(x) = ax2 + bx + c مع a ≠ 0، منحناها قطع مكافئ.
  5. الرأس: فاصلته α = −b ÷ (2a) وترتيبه β = g(α)، والمستقيم x = α محور تناظر.
  6. الشكل النموذجي: g(x) = a(x − α)2 + β.
  7. إذا كان a > 0 فـ g متناقصة ثم متزايدة (قيمة حدية صغرى β)، وإذا كان a < 0 فالعكس.

🟢 أمثلة تطبيقية

  1. f(x) = 2x − 3. الحل: a = 2 > 0 فهي متزايدة؛ f(0) = −3 وf(2) = 1، وتنعدم عند x = 1,5.
  2. g(x) = x2 − 4x + 3. الحل: α = 4 ÷ 2 = 2، β = 4 − 8 + 3 = −1، إذن g(x) = (x − 2)2 − 1، متناقصة على ]−∞ ; 2] ومتزايدة على [2 ; +∞[.
  3. حلول g(x) = 0. الحل: (x − 2)2 = 1 ⇒ x − 2 = 1 أو x − 2 = −1، أي x = 3 أو x = 1. تحقق: (x − 1)(x − 3) = x2 − 4x + 3.

🟠 أخطاء شائعة في البكالوريا

  • نسيان إشارة السالب في α = −b ÷ (2a).
  • الخلط بين المعامل الموجّه a والترتيب إلى المبدأ b.
  • رسم القطع المكافئ بزاوية حادة عند الرأس بدل شكل منحنٍ متناظر.
  • كتابة (x − 2)2 = x2 − 4 بدل x2 − 4x + 4.

🟡 خلاصة للمراجعة السريعة

  • تآلفية: مستقيم، وإشارة a = اتجاه التغير.
  • درجة ثانية: قطع مكافئ، رأسه عند α = −b ÷ (2a).
  • a > 0: فتحة نحو الأعلى وقيمة صغرى.
  • الشكل النموذجي يعطي الرأس والجذور بسهولة.
