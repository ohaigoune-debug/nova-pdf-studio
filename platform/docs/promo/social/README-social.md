## 3. خطوات الإنشاء (من الهاتف)

**فيسبوك**
1. تطبيق فيسبوك ← القائمة ← **الصفحات** ← **إنشاء** ← الاسم «مدرسة — Madrasa DZ» ← الفئة «موقع تعليمي» ← الوصف أعلاه.
2. صورة الصفحة: `profile-logo-1080.png` · الغلاف: `facebook-cover-1640x624.png`.
3. **تعديل الصفحة** ← اسم المستخدم `madrasadz` ← الموقع `https://madrasadz.com` ← زرّ الإجراء «تعرّف على المزيد».
4. أضف الهاتف/واتساب الخاص بالدعم إن أردت استقبال الرسائل (لا تضع رقمك الشخصي إن كنت لا تريد ذلك).
5. ثبّت `madrasa-promo-59s.mp4` كأول منشور مثبّت.

**إنستغرام**
1. أنشئ حساباً بالبريد الذي تريد ← اسم المستخدم `madrasadz` ← الاسم «مدرسة | Madrasa DZ».
2. الإعدادات ← **نوع الحساب** ← التحويل إلى **حساب احترافي** ← الفئة «تعليم».
3. الصورة `profile-logo-1080.png` · النبذة أعلاه · الرابط `https://madrasadz.com`.
4. **ربط الحسابين:** إنستغرام ← الإعدادات ← مركز الحسابات ← إضافة حساب فيسبوك ← اختر الصفحة. بعدها يُنشر من **Meta Business Suite** (business.facebook.com) على المنصّتين معاً وبجدولة.

**الأمان**
- فعّل المصادقة الثنائية على الحسابين.
- لا تكتب أي كلمة سرّ أو مفتاح في المنشورات أو الرسائل.
- لو احتجت أن أدير النشر لاحقاً، يكون ذلك عبر أدوات Meta الرسمية (صلاحية «محرّر» للصفحة) لا عبر كلمة سرّك.
