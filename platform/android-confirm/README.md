# تطبيق عامل التأكيد (أندرويد)

تطبيق صغير لموظفي التأكيد فقط: يفتح صفحات `https://madrasadz.com/worker` داخل التطبيق.

- **الدخول** برقم الهاتف وكلمة السر (حساب «موظف تأكيد» من الإدارة ← الموظفون).
- **حجوزاتي** (بطاقة زبون واحدة كاللعبة): عند الفتح تُحجز 10 طلبات تلقائيًا. لكل زبون «اتصل» كبير يطلب الرقم مباشرة،
  وأدوات: تعديل · تفعيل · حظر · حذف. بعد «اتصل» ثلاث خانات: تأكيد · لا يجيب · إلغاء، فتطير البطاقة ويصعد الزبون الموالي
  حتى تنتهي الحجوزات، ثم شاشة النتيجة مع «جولة ثانية: من لم يُجب» و«احجز دفعة جديدة».
- الجولة محفوظة في الهاتف: الرجوع من المكالمة أو إعادة فتح التطبيق يعيد الموظف إلى البطاقة نفسها.
- **بحث وتفعيل**: برقم الهاتف أو رقم الطلب — «سُلِّم وتفعيل الدورة»، «كود التفعيل»، «إرسال إلى EcoTrack».

كل المنطق والصلاحيات في الخادم؛ تحسين الصفحات يصل العمّال فورًا بلا تحديث للتطبيق.
الصفحات نفسها تعمل أيضًا من متصفح أي هاتف أو حاسوب على `madrasadz.com/worker`.

| | |
|---|---|
| المعرّف | `dz.madrasa.confirm` |
| أقل إصدار | أندرويد 8.0 (API 26) |
| الأذونات | الإنترنت، والاتصال المباشر (يُطلب عند أول «اتصل»؛ إن رُفض تُفتح لوحة الأرقام) |
| المكتبات | لا شيء — Android SDK وحده |

## البناء والنشر (على الخادم)

```sh
cd /opt/madrasa/platform && bash scripts/build-android-confirm.sh
```

ينشئ مفتاح توقيع خاصًا في `/opt/madrasa/android-confirm-key` (لا علاقة له بمفتاح تطبيق التلاميذ)،
ويبني APK موقّعًا، وينشره على `https://madrasadz.com/download/confirm-app`.
أعد تشغيله متى شئت: رقم الإصدار يزيد تلقائيًا فيتحدّث التطبيق فوق القديم.
**احفظ نسخة من مجلد المفتاح خارج الخادم.**

## تثبيته عند العامل

1. افتح `madrasadz.com/download/confirm-app` من هاتفه، ونزّل الملف.
2. اسمح بالتثبيت من هذا المصدر عندما يطلب أندرويد ذلك، ثم ثبّت.
3. ادخل برقم هاتفه وكلمة سرّه. عند أول «اتصل» اسمح للتطبيق بإجراء المكالمات.
