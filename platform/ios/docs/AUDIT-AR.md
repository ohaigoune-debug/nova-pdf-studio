لم يُعثر في الفحص الأولي على مشروع Xcode أو إعداد Capacitor قائم. الموجود `platform/android` تطبيق Trusted Web Activity، ولا يصلح مشروع Android نفسه للبناء على iOS. لم يُغيّر هذا العمل Android أو أسرار النشر.

## القرار التقني

SwiftUI مع WKWebView يحافظ على خادم Next.js وServer Actions والحسابات والصلاحيات الحالية، ويضيف أدوات دراسة أصلية صغيرة. لا static export، ولا نقل Drizzle أو أسرار الخادم إلى الجهاز. الغرض تقليل الصيانة دون جعل التطبيق مجرد شاشة رابط.

نطاق نسخة العمل: ثلاثة تبويبات أصلية للتعلّم والمفضلة وخطة المراجعة، بوابة `/ios` ثابتة النطاق، جلسة الموقع داخل مخزن WebKit المستمر، رصد هوية محدود من الخادم، خروج يلغي الجلسة خادميًا ثم يمسح البيانات المحلية، مفضلة ومهام معزولة بحسب الحساب وتذكيرات محلية باختيار المستخدم، بحد أقصى 50 تذكيرًا. لا مكتبة PDF أو فيديو دون اتصال في هذه النسخة. أضيف تصدير PDF مؤقت ومصرّح به إلى أداة مشاركة iOS عند طلب التنزيل صراحة من واجهة الدرس؛ ليس تنزيلًا تلقائيًا أو ترخيصًا للعمل دون اتصال.

## ما هو موجود فعليًا في المنصة

| المجال | المسارات/السلوك المفحوص |
|---|---|
| الدخول والتسجيل | `/login` و`/register` بإجراءات خادم وحساب STUDENT عادي؛ لا قاعدة حسابات جديدة |
| الجلسة | `madrasa_session` من نوع HttpOnly، وSecure في الإنتاج وSameSite=Lax؛ الخادم يتحقق من الصلاحية والسحب وحالة المستخدم |
| الهاتف | بوابة تحقق للحسابات الجديدة وفق القنوات والسياسة؛ يجب ألا تتجاوزها الأدوات الأصلية |
| الاسترجاع | البريد والهاتف في `/forgot-password`، وروابط/OTP محدودة الاستخدام؛ تغيير السر يلغي الجلسات |
| حذف الحساب | الإجراء الفعلي في `/student/profile#delete`؛ `/delete-account` صفحة توضيحية؛ راجع حدود الحذف أدناه |
| الدروس | `/lessons` و`/student/lessons` وتفاصيلها، مع قواعد نشر/أفواج/اشتراك |
| الفيديو | `/videos` و`/student/videos`؛ YouTube وBunny Stream وملفات مرفوعة محمية |
| الاختبارات والمراجعة | `/student/quizzes` و`/student/exams` و`/student/practice` وبنوك BAC والمكتبة والأرشيف |
| اللعبة التعليمية | `/student/play` وأسئلة وتحديات وأخطاء سابقة؛ وجود المسار لا يثبت توافر محتوى إنتاجي معين |
| الدورات | `/student/courses` وتفاصيلها؛ المصدر يملك شراء كتاب يفعّل الدورة عند التسليم |
| الأفواج والنشاط | حضور وواجبات ودرجات وفصل وتعليقات وفق دور المستخدم |
| المنتدى | قراءة وكتابة وردود، وإشراف إداري؛ لم يُثبت إبلاغ وحظر مستخدمين مكتملان |
| المتجر | BOOK/PDF/PACK، COD/تحويل/مجاني، وتفعيل مرتبط بالطلب؛ ليس استثناء Apple مؤكدًا |
| الدعم | `/student/support` وتذاكر الحساب؛ عنوان التواصل العام يُضبط عبر CONTACT_EMAIL أو ADMIN_EMAIL |

هذه قائمة إمكانات المصدر، وليست إعلانًا بأن كل مساحة معروضة في الإصدار الأول من iOS. نطاق iOS يستبعد التجارة والأكواد والمجتمع، وتُراجَع المسارات المسموحة في سياسة التنقل. وضع العرض يثبت عبر ترويسة `/ios` وكوكي مخصص، ويشمل middleware طلبات RSC/prefetch؛ هذه الإشارة تختار واجهة محددة ولا تثبت هوية أو اشتراكًا. الويب العام دون الكوكي يحتفظ بنموذجه الحالي.

## الحسابات والأمان

إعادة استخدام تسجيل الموقع داخل WKWebView تتجنب جمع كلمة السر في Swift أو افتراض أن Bearer API يضع كوكي المتصفح. API الدخول الموجود يعيد رمزًا ولا يضع كوكي WebKit تلقائيًا. لا OAuth اجتماعي موجود في المصدر المفحوص؛ ذكر Google هو Drive/YouTube/Meet، لا تسجيلًا اجتماعيًا.

معرّف الحساب الذي يعيده API المحدود مخصص لتقسيم البيانات المحلية، وليس إثبات صلاحية للمحتوى. لا User-Agent ولا حقل iOS يفتح الاشتراكات. لا رموز جلسة في روابط المفضلة أو الجسر أو السجلات. الجسر، إن استُخدم، محصور بالإطار الرئيسي والأصل HTTPS الموثوق وأوامر محددة؛ إطارات الفيديو الخارجية لا تملك امتيازاته.

ملفات الدروس المحمية تستخدم تحقق وصول وتوقيعًا قصير العمر. لا يُحوَّل رابط موقّع إلى مفضلة دائمة، ولا تُشارك روابط ملفات exp/sig أو كلمة السر أو الرموز. عرض PDF يبقى عبر المسار المحمي. عند طلب Download من LessonMedia، يمكن تصدير نسخة مؤقتة فقط إذا أجازها الخادم: `GET /api/v1/ios/materials/[contentId]/export` يتحقق من كوكي STUDENT وبوابة الهاتف وresolveMediaAccess وقبول الشروط وجاهزية READY و`allowDownload === true` ونوع PDF وحد 25MiB. يحمّل العميل بذاكرة جلسة ephemeral، ويتحقق من UUID الحساب الذي يعيده الخادم ومن الحساب الحالي قبل العرض في UIActivityViewController. تُحذف نسخته المؤقتة بعد إغلاق المشاركة أو تغير سياق الحساب أو الخروج أو إعادة التشغيل. لا تصدير فيديو ولا مكتبة ملفات دورة دون اتصال. النسخة التي يختار المستخدم تصديرها خارج التطبيق لا يمكن استردادها لاحقًا؛ أما رابط درس عادي فلا يمنح المستلم الاشتراك.

## حدود مهمة قبل المتجر

- حذف الطالب الحالي يمحو بعض بيانات الهوية ويلغي الجلسات، لكنه لا يثبت إزالة كل PII من الطلبات والدعم والمنتدى والمرفقات والسجلات. يلزم تدقيق حذف/احتفاظ وتحديث صياغة الخصوصية قبل التقديم؛ لا يكفي تسميته تعطيلًا.
- سياسة `/privacy` المفحوصة مؤرخة سبتمبر وتذكر Android، وتصف الهاتف اختياريًا رغم التسجيل الحالي، ولا تغطي نطاق iOS ومقدمي الخدمات الأحدث كاملًا.
- المنتدى يملك إخفاء وقفلًا وحذفًا إداريًا، لكن ذلك لا يعوض متطلبات الإبلاغ والحظر لدى Apple. يستبعد الإصدار الأول هذه المسارات بشكل ثابت، مع بقاء العائق موثقًا قبل أي توسيع.
- حماية الفيديو تشمل صلاحيات وتواقيع ومتابعة جلسة وعلامة مائية HTML. ليست FairPlay DRM ولا ضمانًا لمنع تصوير الشاشة أو حفظ الفيديو. قد لا تظهر طبقة HTML فوق المشغل الأصلي في ملء الشاشة؛ يلزم اختبار جهاز.
- تمكين المحتوى الرقمي المشترى على الويب لا يثبت استثناء 3.1. يجب حسم نموذج البيع قبل التقديم، حتى إن لم يظهر زر شراء داخل التطبيق.

## إثبات التنفيذ والاختبارات

بيئة الإعداد Linux، بلا Xcode أو محاكي iOS. لا يُدعى هنا نجاح build iOS أو تسجيل دخول WKWebView أو فيديو أو جلسة جهاز. نتائج الاختبارات الفعلية تسلَّم من تشغيلها، وحالات الجهاز في [DEVICE-TEST-MATRIX.md](DEVICE-TEST-MATRIX.md). معلومات HTTP العام في [PUBLIC-HTTP-CHECKS.json](PUBLIC-HTTP-CHECKS.json) إن اكتمل الطلب؛ لا تكشف إعداد قاعدة البيانات أو SHA الإنتاج.

فحص أخير للمصدر كشف أن CSP كان يمنع نطاق مشغل Bunny الحالي. أُضيف `https://iframe.mediadelivery.net` وحده إلى frame-src مع اختبار فشل قبل الإصلاح ونجح بعده؛ لا wildcard أو تخفيف لسياسة النماذج والإطارات العليا. لا يثبت ذلك تشغيل Bunny فعليًا على جهاز؛ هذه الحالة ما زالت ضمن مصفوفة الاختبار.
