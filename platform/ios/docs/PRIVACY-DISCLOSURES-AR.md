# مسودة إفصاحات الخصوصية والأذونات

تاريخ الجرد: 26 أكتوبر 2026. هذه مسودة مبنية على المصدر والنطاق الحالي، وليست سياسة قانونية منشورة أو إجابات أُرسلت إلى App Store Connect. يجب مطابقة الأرشيف النهائي ومقدمي الخدمة والإعداد الفعلي قبل التقديم.

## الفصل بين المحلي وما يغادر الجهاز

| البيانات | الموضع والغرض | الإفصاح المتوقع |
|---|---|---|
| PDF مصرح بتصديره | تنزيل مؤقت إلى مجلد محمي خاص بالحساب بعد طلب المستخدم، ثم مشاركة عبر iOS | تُزال النسخة المؤقتة عند إتمام المشاركة وتغير السياق والخروج وإعادة التشغيل؛ ما يحفظه المستخدم خارج التطبيق لا يمكن سحبه لاحقًا |
| روابط المفضلة وعناوينها | تخزين محلي معزول بحسب الحساب لتسهيل الرجوع | لا تُعد مجمعة لدى المشغّل إذا لم تُرفع أو تُزامن؛ يحذفها الخروج وفق تنفيذ التطبيق |
| مهام المراجعة ومواعيدها | تخزين محلي؛ التذكير عبر نظام iOS باختيار الطالب | لا مزامنة سحابية أو APNs من هذا النطاق؛ لا تفترض إرسالها للخادم |
| كوكي جلسة الموقع | مخزن WebKit المستمر، يرسَل إلى أصل الموقع عبر HTTPS | جلسة حساب فعلية؛ لا كلمات سر في Keychain أو روابط المفضلة ولا نسخ للجلسة إلى مواقع خارجية |
| معرّف الحساب المحدود | يعيده الخادم لتقسيم البيانات المحلية | ليس تصريح وصول ولا بديلًا عن صلاحيات الخادم؛ لا ضرورة لإرجاع البريد والهاتف لهذا الغرض |
| الاسم والبريد والهاتف وبيانات الحساب | تسجيل الموقع وإدارة الحساب والتحقق والاسترجاع | بيانات اتصال ومعرّف مستخدم، مرتبطة بالحساب، لغرض وظائف التطبيق والأمان |
| بيانات المدرسة والمستوى والشعبة والولاية وهاتف الولي | ملف الطالب وفق النموذج الحالي | تصنيف حسب الحقول الفعلية: بيانات اتصال أخرى ومعلومات ملف؛ الموقع الإداري ليس إذن GPS |
| نتائج الاختبارات والتسليمات والنشاط | خادم المنصة لتقديم التعليم والصلاحيات والتقدم | تفاعل منتج/محتوى مستخدم/بيانات أخرى وفق الجرد الفعلي، مرتبطة بالحساب |
| تذاكر الدعم ومرفقات تعليمية عند إتاحتها | خادم المنصة عند استعمال المسارات المسموحة | خدمة عملاء ومحتوى مستخدم، وقد تتضمن صورًا أو ملفات بحسب الوظيفة |
| IP ومعلومات الجهاز والجلسة | سجل الخادم للحماية ومكافحة التخمين وإدارة الأجهزة | يصنف وفق استعماله ومدة احتفاظه؛ لا يُحوّل تلقائيًا إلى ادعاء جمع موقع دقيق أو معرّف إعلاني |
| سجل مشتريات/عنوان توصيل سابق | قد توجد بيانات بالحساب من الويب؛ التجارة ليست ضمن نطاق iOS الحالي | جرد ما يُعرض/يجمع فعليًا في التطبيق؛ لا تُخفِ بيانات تجمعها WebView من الإفصاح |

Apple تنص صراحة أن البيانات المجموعة عبر web traffic داخل WebView تُعلَن، إلا إذا كان التطبيق متصفحًا للويب المفتوح. تطبيق مدرسة ليس متصفحًا عامًا. لا يصح اختيار «Data Not Collected» لمجرد عدم وجود SDK تحليلات أصلي.

## التتبع ومقدمو الخدمة

لا يضيف نطاق iOS الحالي شبكة إعلانات أو معرف IDFA أو SDK تحليلات أو تتبعًا عبر التطبيقات. يجب أن تتطابق قيمة NSPrivacyTracking وإجابات App Store Connect مع السلوك الفعلي للويب والمكتبات المضمّنة، بما في ذلك الفيديو؛ غياب SDK Swift لا يكفي وحده.

المصدر يشير إلى استضافة Contabo، وبريد Resend، وقنوات SMS قابلة للضبط، وEcoTrack لطلبات الويب، وYouTube-nocookie وBunny للوسائط، وميزات OpenAI بحسب تفعيلها. هذه قائمة مسارات معالجة محتملة وليست إثبات أن كل موفر مفعّل لكل طالب. يجب تأكيد المعالجات الحقيقية والسياسة المنشورة دون نسخ أسرارها. لا تدّعِ أن وضع YouTube المحسن للخصوصية يمنع كل معالجة لدى Google.

## الأذونات

- الإشعارات المحلية اختيارية، ويُطلب الإذن عند تمكين التذكير، مع بقاء الدراسة والخطة مفيدتين عند رفضه. لا يلزم APNs أو مفتاح دفع لمجرد تذكير محلي.
- لا يُطلب إذن الموقع أو جهات الاتصال أو الميكروفون أو كاميرا أو مكتبة الصور لتشغيل هذا النطاق.
- لا صلاحية ATT أو نص تتبع إذا لم توجد وظيفة تتبع تتطلبها؛ يُراجَع أي تغيير لاحق.
- مشاركة رابط أو PDF مصرح به عبر أداة iOS لا تمنح التطبيق قراءة جهات الاتصال، ولا تضمن سحب ما نسخه المستخدم خارجه.
- إذا أتاح رفع ملف عبر الموقع منتقي نظام، اختبره على جهاز وراجع الأذونات بحسب السلوك الفعلي؛ لا تضف أوصاف أذونات احتياطية لوظائف غير منفذة.

## PrivacyInfo.xcprivacy وRequired Reason APIs

وجود Privacy Manifest ليس بديلًا عن سياسة الخصوصية وإجابات المتجر. يراجع الأرشيف النهائي عبر Xcode Privacy Report، وتُفحص المكتبات المضمّنة إن أضيفت.

فحص المصدر الحالي لم يجد UserDefaults أو APIs لتوقيت الملفات أو مساحة القرص أو وقت الإقلاع. `FileHandle.read/seekToEnd/seek` و`URLResourceKey.fileSizeKey/isRegularFileKey/isSymbolicLinkKey` وضبط FileProtection/استبعاد النسخ الاحتياطي ليست ضمن قائمة API المشمولة المنشورة في مصدر Apple المفحوص؛ لا يضاف سبب عام لمجرد التعامل مع ملف. لذلك تبقى مصفوفة NSPrivacyAccessedAPITypes الأولية فارغة، مع إعادة فحص الأرشيف النهائي وأي مكتبة لاحقة. هذا فحص مصدر وليس تقرير Privacy Report من Xcode، ولا يبرر اختيار Data Not Collected للخدمة.

| API | القاعدة |
|---|---|
| UserDefaults | CA92.1 عندما تكون القراءة والكتابة لإعدادات التطبيق نفسه فقط؛ يصرح به فقط إذا استعمله التطبيق |
| توقيت/حجم/بيانات وصفية للملفات عبر APIs المشمولة | يلزم السبب المعتمد الموافق، مثل C617.1 لملفات حاوية التطبيق عند انطباقه؛ لا يضاف بلا استعمال |
| مساحة القرص أو وقت إقلاع النظام | أسباب مستقلة عند استعمال APIs الفعلية؛ ليست مطلوبة لمجرد استخدام Date أو Keychain |
| Keychain / URLSession / التذكيرات المحلية | لا تُبرّر تلقائيًا إضافة فئات required-reason أخرى |

NSPrivacyCollectedDataTypes يجب ألا تتناقض مع جمع الحساب والمحتوى عبر WebView والخادم. أي قيم أولية تُراجع مع نطاق المسارات الحقيقي قبل التقديم؛ لا تُفسَّر مصفوفة محلية فارغة على أنها شهادة أن الخدمة لا تجمع بيانات.

## الخروج والتبديل وانتهاء الصلاحية

بعد خروج مؤكد من الخادم تُمسح بيانات WebKit المحلية وبيانات الحساب الأصلية وتذكيراته. فشل الشبكة لا يعني نجاح إلغاء رمز الخادم؛ يجب إظهار حالة صادقة وإتاحة إعادة المحاولة أو قفل محلي مميز. عند تبديل الحساب لا يُعرض محتوى المفضلة أو الخطة السابقة أثناء التحقق من الهوية.

لا تحفظ هذه النسخة PDF أو فيديو في مكتبة دورة دون اتصال. تسمح بتصدير PDF مؤقت فقط بطلب Download صريح، بعد تحقق خادمي من الجلسة والحساب وبوابة الهاتف والوصول وقبول الشروط وREADY وallowDownload ونوع PDF وحد 25MiB. يُعاد UUID الحساب مع الرد، ويتحقق العميل من ثبات الحساب قبل إظهار UIActivityViewController، دون حفظ كوكي الجلسة أو مشاركة توقيع الملف. النسخة المؤقتة محمية ومعزولة بحسب الحساب وتُنظّف بعد الإغلاق/تغير الحساب/الخروج/إعادة التشغيل. لا تصدير فيديو. قد يستخدم WebKit ذاكرته/تخزينه الداخلي أثناء العرض؛ لا يعني ذلك ضمان عدم وجود أي بايت مؤقت. لا ادعاء بسحب نسخة أجاز الخادم تصديرها ثم حفظها المستخدم خارج التطبيق، أو بإلغاء صلاحيتها بأثر رجعي.

## حذف الحساب والاحتفاظ — عائق قبل التقديم

المسار الحالي يتيح للطالب بدء الحذف بكلمة السر وتأكيد صريح. يمحو بعض بيانات الهوية ويلغي الجلسات وينهي عضوية الأفواج. لم يثبت تدقيق المصدر إزالة PII من الطلبات والدعم ومنشورات المنتدى والمرفقات والرموز وسجلات النشاط. Apple تتطلب حذف الحساب والبيانات المرتبطة، مع بيان ما يلزم الاحتفاظ به قانونًا. لا تستخدم عبارة «يُحذف كل شيء نهائيًا» قبل معالجة هذه المجالات واختبارها.

يحتاج المشغل قرارًا مكتوبًا بمدد الاحتفاظ وأسبابها والنسخ الاحتياطية والمستلمين، وآلية حذف/إخفاء هوية البيانات المرتبطة. إضافة رابط الحذف في iOS لا تصلح وحدها نقص نطاق الحذف في الخادم.

## السياسة العامة المطلوبة

يُحدّث `https://madrasadz.com/privacy` لتغطية iOS والتذكيرات والمفضلة المحلية وOTP والهاتف المطلوب والخدمات الفعلية وسياسة الحذف والاحتفاظ والقاصرين ووسيلة تواصل عاملة. جرى العثور على الرابط في المصدر؛ حالة الوصول العام في [PUBLIC-HTTP-CHECKS.json](PUBLIC-HTTP-CHECKS.json). هذا العمل لا ينشر تعديل سياسة على الإنتاج.

الفحص العام في 26 أكتوبر 2026 أعاد الحالة 200 لصفحة الخصوصية، وبها بريد التواصل المنشور `ohaigoune@gmail.com`. هذا دليل توافر صفحة، وليس تصديقًا على اكتمال محتواها أو موافقة المالك على استعمال البريد في App Store Connect.

الجمهور يشمل قاصرين؛ لا يُختار Kids Category أو عمر 4+ تلقائيًا. تُملأ استبيانات العمر بناء على المحتوى والمجتمع وAI والويب في النطاق الفعلي، وتُراجع موافقات الولي ومتطلبات المناطق مع المشغل.
