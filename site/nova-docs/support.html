NOVA Docs

Support

NOVA Docs works fully offline. For help, write to ohaigoune@gmail.com — answers in Arabic, French or English, usually within 48 hours.

Restore NOVA Pro

Open the app → More → Restore purchases, signed in with the same Apple ID used for the purchase.

Refunds

Refunds are handled by Apple: reportaproblem.apple.com or More → Request a refund in the app.

Where are my files?

Open the Files app → On My iPhone/iPad → NOVA Docs. Nothing is uploaded to any server.

الدعم

يعمل NOVA Docs دون إنترنت. للمساعدة راسلنا على ohaigoune@gmail.com — نجيب بالعربية أو الفرنسية أو الإنجليزية خلال 48 ساعة غالبًا.

استعادة NOVA Pro

المزيد ← استعادة المشتريات، بنفس حساب Apple المستعمل في الشراء.

الاسترداد

تتولاه Apple عبر reportaproblem.apple.com أو من التطبيق: المزيد ← طلب استرداد المبلغ.

أين ملفاتي؟

تطبيق الملفات ← على iPhone/iPad ← NOVA Docs. لا يُرفع أي ملف.

Assistance

NOVA Docs fonctionne hors ligne. Écrivez à ohaigoune@gmail.com. Restauration : Plus → Restaurer les achats. Remboursements : gérés par Apple. Vos fichiers : app Fichiers → Sur mon iPhone/iPad → NOVA Docs.
